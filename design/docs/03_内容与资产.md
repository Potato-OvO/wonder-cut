### 5.1 造型硬约束（**自动体检，不过不许进包**）

> 这五条不是美术偏好，是体素分辨率 + 刮削机制硬性决定的。**它们限制的是"厚度"，不是"形状"**——歪、缺角、扇贝边、表面凹凸全都可以。

| 约束 | 阈值 | 为什么 |
|---|---|---|
| 最小局部厚度 | **≥10mm**（≈6 体素） | 更薄的部位在 48³ 下只剩 2~3 体素，网格化后会锯齿/断裂 |
| 连接处（颈/腰） | **≥10mm** | 细颈会被一刀削断，变成悬浮孤岛 |
| 最大内切球半径 | **≥12mm** | 没有够厚的"肚子"，核心腔无处安放，整局没有主藏品 |
| 单连通 | 必须 | 镂空环、悬空把手会先断成两块 |
| 尖端圆化 | 半径 ≥3 体素 | 尖刺的体素不足以支撑网格，会破面 |

**允许的"不规整"**：歪斜、缺角、扁/鼓、表面凹凸、噪声起伏、多体融合的葫芦形、半球伞盖、碗、螺旋。
**禁止的"不规整"**：细长触角/鹿角、薄片/翼/鳍、细颈、镂空环、尖刺、多分支。

> **参考图正好是"允许"的典型**：那块绿坯歪、缺角、边缘扇贝状，但整体很"肉"，没有一根细杆——所以它成立。
> 若某款确实需要"尖"的造型（如甜筒底），做法是**圆化收口**：锥体收到 10mm 圆头，而不是收到尖点，观感仍然是"锥"。

### 5.2 材质贴图要求

- **配色只交 1 张中性色底图**（明度居中、饱和度低）。3 色变体由程序用 shader 色相/明度参数生成；**验收时若发现"每色一张贴图"，一律退回**
- **一张贴图要同时表达"外表"和"切面"两种质感**：
  - 外表：更光滑、颗粒细
  - 切面：略深、颗粒更粗、有细密拉丝痕
  - 做法：1 张 baseColor + 1 张法线/粗糙度，程序按 `originDist`（挖深）在两者之间插值。**不要交两套贴图**
  - 光泽/粗糙度差异由引擎粗糙度贴图控制；生图 prompt 不写"高光/稍亮/哑光"等词（见 `04` §0.3 禁用清单）
- 贴图必须**可无缝平铺**（三平面投影会重复采样）

**说明与余量**
- **坯体零模型资产**：16 款坯不需要建模，只需 16 组造型参数，省下的不只是包体还有整条建模工期
- 真正的增量是**隐藏物从 2D 贴图变成 3D 低模**（+2.4MB）和**卷片 mesh**（+0.2MB），被省掉的坯体贴图基本抵消

- 分包：首包只放 UI + 首套装材质与隐藏物，深海套装按分包加载
- 季节限定套装走**分包或远程资源**，不要塞进主包
