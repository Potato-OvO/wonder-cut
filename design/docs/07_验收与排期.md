# 第一部分：验收标准

## 1. 阶段 0 Gate（**生死线，不过就换方案**）

| # | 条件 | 通过标准 |
|---|---|---|
| 1 | 低端安卓真机帧率 | **≥30fps**，连续刮削 60 秒不掉帧、不闪退 |
| 2 | 网格重建 | 单块 **<3ms**，连续刮削时**没有 GC 卡顿** |
| 3 | 视觉样片 | 能看出"立体、凹槽、扇贝边、卷片"四件事，**且异形坯（缺角+噪声）不破面** |

> **任一不通过 → 退到降级方案（多层同心壳侵蚀）**，不要硬扛体素。降级方案视觉弱一档（洞是平洞、没有凹槽），但能保上线。
> 判定为什么不回读像素：微信小游戏从 RenderTexture 读像素不可靠且极慢，判定一律走 CPU 密度场。

### 2.3 立体减材 & 揭示

- [ ] 不同材质刮削手感、音效、震动区分正确
- [ ] 坯体可在**任意角度**转动（两个触控盘**功能一致**，拖任意方向都能转），转走再转回**刮削痕迹保留**

- [ ] 水平方向能转满 360°；**拖出盘外仍跟手**（能转超过一圈）
- [ ] 仰角到 ±85° 有回弹提示，且不会转到底朝天

- [ ] **双指操作完全不生效**：两指同时拖动不触发任何旋转或刮削
- [ ] 刀头从任意表面下刀都能削出**弧形凹槽**，不是平面切口
- [ ] 反复平行刮后边缘呈现**扇贝状波浪**
- [ ] 削下来的**卷片成条飞出并保持形状**，不是 2D 碎片
- [ ] 削到极限时几何不破面、不出现孤岛、不出现翻转法线
- [ ] 核心腔判定符合配置：空腔 35% / 小物 20% / 主藏品 45%（稀有档）
- [ ] 空腔产出 1 枚空响币，任意一局结算金币 ≥ 本局埋藏腔数
- [ ] 首次开出主藏品，图鉴点亮，永久保存
- [ ] 砸碎坯拿到 30% 保底奖励，不扣分
- [ ] 收工后未开腔位作废，结算不出现空奖励或负数
- [ ] 挖穿兜底：残余体积 <8% 时正确结算全额
- [ ] 传说坯触发慢镜头+粒子高光
- [ ] 主藏品不会被普通刀具切碎，锤子可以砸碎
- [ ] 三层色带随削深递减，切面比外表更哑光/略深可感知
- [ ] 距埋藏腔 3mm 内出现结构信号，空腔与有物腔信号一致
- [ ] 宽扫/深钻切换后刀头半径与削深变化，主藏品出率不变
- [ ] 进度环只反映已削**体积**，不出现评分或颜色警示
- [ ] 收工后剩余腔位作废，二次进入不能补挖

### 2.4 体素与性能（**每版必测**）

- [ ] 开局生成密度场与 `originDist` 在 100ms 内完成，加载动画不卡
- [ ] 连续刮削 60 秒不闪退、不掉帧（低端安卓 ≥30fps）
- [ ] 脏块重建不触发 GC 尖峰（看 Profiler 的 GC 曲线）
- [ ] 一帧最多重建 2 块，超出排队到下一帧
- [ ] 低配模式切到 32³ 后仍可正常刮削，卷片降到 8 条
- [ ] 密度场内存 <1MB，整局不增长（无泄漏）
- [ ] 同一坯反复重置 10 次，内存与帧率无劣化

### 2.5 造型约束（**16 款坯逐款过**）

- [ ] 异形坯（缺角/伞盖/双体/螺旋）刮削时边缘不崩、不破面
- [ ] 薄处削深被自动压制（不会"一碰就穿"），厚处正常削深

# 第二部分：排期

> 角色：单人开发者（策划 + 美术 + 程序 + 测试）
> **程序 64 天**（含 V1.1a 预产 3 天）+ 美术 18~26 天 + 音频 3~5 天 + 缓冲 6~10 天 = **约 91~105 工作日（约 4.5~5 个月）**
> 相对 2D 方案：程序 **+14 天**（体素系统、MC 重建、SDF 拾取、3D 相机与双触控盘、3D 材质与光照），美术 **-4 天**（坯体不建模，但隐藏物 3D 化）
> 阶段天数合计：5 + 10 + 11 + 6 + 10 + 12 + 10 = **64 天**

## 阶段 0：灰盒 Spike（5 天出结论，允许顺延至 7 天，不投入美术）

> 用「1 个材质 + 1 款坯 + 无抽卡无图鉴无美术」验证生死线，失败也只损失 5~7 天。
> **这是本次改版最关键的 5 天**：立体减材能不能在微信低端机跑起来，只有真机说了算。

| 序号 | 任务 | 交付物 |
|---|---|---|
| 0-1 | 程序化 SDF 坯体 → 48³ 密度场 → 全量 MC 重建 → 正常渲染 | 渲染路线确认 |
| 0-2 | 笔刷减材 + 脏块局部重建：测**单块重建耗时**与连续刮削帧率 | 减材原型 + 性能数字 |
| 0-3 | CPU 密度场 DDA 拾取 + 相机 orbit + **双触控盘（2 轴自由转动）** + 触控分区 | 触控原型 |
| 0-4 | **异形坯试刮**：缺角+噪声的非盒非球坯，验证不破面、薄处不穿透 | 异形坯结论 |
| 0-5 | 色带着色（`originDist`）+ 卷片 mesh 飞出 + 音效触发点 | 视觉样片 |
| 0-6 | **低端安卓真机实测**：≥30fps，单块重建 <3ms，单帧重建 ≤2 块 | 真机性能报告 |

**Gate 见第一部分 §1。**

# 第三部分：风险点与缓冲

1. 微信广告 SDK 审核经常驳回，预留 1~2 天；**纯 IAA 无内购**，不涉及支付与版号
2. **最大风险是动态网格重建的 GC 抖动**：低端机表现为"刮两下卡一下"。优先用预分配 buffer + 脏块限流解决；解不掉就走阶段 0 降级方案
3. 低端安卓性能不足时，优先**降密度场分辨率（48³→32³）**、降卷片数量，**不要降触控采样率**（那会毁手感）
4. 美术会占用大量时间，**先做核心坯造型配方 + 4 个传说隐藏物**，次要 UI、普通粒子后补
5. **手感调优（阶段 5）不可压缩**：压缩它等于压缩这个品类的唯一护城河
6. **3D 美术产能是新风险点**：16 个隐藏物从 2D 贴图变成 3D 低模。若自建模型卡住，先用"基础几何拼装 + 材质"顶上，**不要为单个隐藏物卡 3 天**
7. **视觉令牌已锁定**（2026-11-11）：样张与色板/光照/材质话术见 `04` §0.2/§0.3；美术按令牌批量出图，风格不得偏离基准样张
