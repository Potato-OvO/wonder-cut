### 0.3 统一生图规范（批量出图前必须套用）

> 本节取代旧版"统一生图 Prompt 模板"。旧版只有一段共用话术，缺少**可判别参数**与**验收标准**，导致首批 4 张样张出现四类偏差：表面气孔、镜面高光、乱码伪文字、同款坯形态漂移。本节逐条堵住。

#### 0.3.1 五条铁律

| # | 铁律 | 原因 |
|---|---|---|
| 1 | **图内不生成任何文字**，文字后期在 Figma / Cocos 叠 | AI 生中文必乱码（首批 2a 副标题即为此）；且 Cocos 里 UI 本就是 Label 叠 Sprite |
| 2 | **先出定妆图，其余用垫图**（image-to-image 强度 0.55~0.70） | 纯文生图每次都重新发明形态，导致同款坯出现方墩/圆台/软团三种样子 |
| 3 | **材质用可判别参数描述**，不用"哑光/高光/细腻" | 这类词模型不可执行且互相冲突，会被随机取一个 |
| 4 | **一次只改一个变量**（先形态 → 再材质 → 最后光照构图） | 同时改多项，出问题查不出原因 |
| 5 | **每张图必须过 §0.3.7 QA 清单** | "看着还行"是返工起点 |

#### 0.3.2 技术参数

| 项 | 值 |
|---|---|
| 尺寸 | **1536 × 2730**（9:16） |
| 格式 | **真 PNG**（禁止 JPEG 改扩展名，标准读取会失败） |
| 每张种子数 | **4**，同 prompt 出 4 张挑最优 |
| 定妆图 | **1 张/款**，必须先过 QA，作为该款所有图的锚点 |
| 材质贴图 | 512² / 1024²，**可无缝平铺**，独立出图（**不垫定妆图**） |

#### 0.3.3 UI 渲染语言（已定：平涂）

**平涂（flat）**：按钮 = 圆角色块 + 1px 描边 + 一层柔和软阴影；图标 = 单色线条；**无厚度、无侧面、无高光**。

- 依据：本节原文与 §1.3 均为"平涂柔和填充"
- 工程理由：平涂可用 Sprite + **9-slice 任意拉伸**，一个色块适配所有尺寸；3D 黏土有固定厚度与光照方向，**无法 9-slice**，每个尺寸都要单独出图，包体与工时翻倍
- 平涂的"塑料/糖果感"为零，不与"干燥压实"的坯体材质语言冲突
- **若改为 3D 黏土**：属令牌变更，需在 `00_状态与决策.md` 决策日志记一行，并重画全部 UI 资产

#### 0.3.4 材质可执行参数（核心）

> 把"干燥压实动力沙"翻译成 6 个可判别参数，直接写进 prompt。**"无气孔"必须写进正向**——只放反向清单会被忽略。

| 参数 | 锁定值 | 为什么是这个值 |
|---|---|---|
| 颗粒直径 | 0.2~0.4mm，均匀细密 | 太小像塑料，太大像砂纸 |
| 气孔 | **0 个**（正向写"完全无气孔/无针孔/无海绵孔"） | 参考图无气孔；气孔 = 泡沫，破坏"压实" |
| 光泽 | 全哑光，无镜面反射、无釉面、无塑料/果冻感 | |
| 切面色差 | 比表皮**深 10~15%**，颗粒更粗 | 这是"挖过多深"的视觉信号 |
| 切面纹理 | **20~40° 平行细拉丝痕** | 参考图的标志性特征 |
| 凹槽几何 | 宽 **6~8mm**、深 **8~10mm**、间距 **4mm**、**竖直并列**、边缘**扇贝 3~5 瓣** | 参考图签名；横向/宽疏即另一种东西 |

#### 0.3.8 16 款坯的批量流程

```text
① 定妆图（1 张/款，纯文生图，过 QA）
      ↓
② 以定妆图为底图，image-to-image 强度 0.55~0.70，出「刮削中」场景图
      ↓
③ 材质贴图单独出：出「可平铺无缝材质」而非「有造型的物体」，
   前缀用 reference/08 §11「材质版」，并追加：
   "seamless tileable, no object silhouette, no background, evenly lit, no shadow, no specular"
   512²/1024²，检查四边接缝能否无缝拼接
      ↓
④ 隐藏物：纯白底、单物体、正交视角 → 图生 3D
```

> **材质贴图不要用定妆图垫**：定妆图是"有造型的物体"，垫出来会带造型阴影，无法平铺。

#### 0.3.10 八个常见坑

| 坑 | 现象 | 解法 |
|---|---|---|
| 让 AI 写字 | 中文乱码 | 图里只画空按钮，文字后期叠 |
| 只写反向不写正向 | 气孔还在 | 正向必须明确写"完全无气孔" |
| 纯文生图出多张 | 每张形态都不同 | 先定妆图，其余垫图 |
| "哑光"与"高光"同时出现 | 模型随机取一个 | 删掉"高光/稍亮/哑光"，改用"无镜面反射" |
| 一次改太多 | 查不出原因 | 一次只改一个变量 |
| 用定妆图垫材质贴图 | 贴图带造型阴影，无法平铺 | 材质贴图独立出，加 "no object silhouette" |
| 导 JPEG 改名 .png | 引擎/工具读取失败 | 导出真 PNG |
| 只看整体不看局部 | 触控盘悄悄变铬银 | 逐条过 QA，重点放大看金属件 |

> **锁定方式**：令牌值变更只改本节与 §1.1，并在 `00_状态与决策.md` 决策日志记一行；批量产出必须引用本节话术与 QA 清单。

### 2.3 坯体操作主页面（核心游戏页）

- 85% 区域：立体坯全屏 3D 操作区（相机绕坯体 orbit）
- **左右两个触控盘（功能完全相同，都是 2 轴自由转动）**：分别放左下、右下，视觉直径约 140px（热区 180px）、半透明、按住才显形。拖向哪个方向，坯体就往那个方向转；**抬手就停在当前角度**，没有惯性拖尾。两盘只是位置不同，方便左手或右手单手操作，**全程不需要双指**
- 底部可收起悬浮工具栏：切换刀具｜重置坯体｜一键回正
- 左上角：中性进度环（已削体积/初始体积），无分数、无颜色警示

- **触控分区**：落在触控盘热区 = 转动坯体；落在坯体上 = 刮削；落在空白 = 无响应（不误刮）

- 导出两套：甜品色系、深海色系

### 4.8 组件 8：双触控盘（**核心交互组件**）

> **两个盘功能完全相同**，不是"左管水平、右管俯仰"。每个盘都是 **2 轴自由转动**：拖向任意方向，坯体就往那个方向转。放两个只是为了让左手或右手都能单手操作，**不需要双指**。

- 尺寸：视觉直径 140px，热区直径 180px（热区比视觉大，好按）
- 图层（从上到下）：
  1. 底盘：圆形，填充 `rgba(216,194,174,0.35)`，1px 描边 `rgba(74,64,64,0.15)`
  2. 方向指示环：一圈细环，拖动时环上出现**偏移的小光点**，指示当前拖动方向与幅度（回中即复位）
  3. 中心握把：小圆点，primary_pink
- 状态变体：
  - **Idle**：整体透明度 30%（几乎不挡画面，但仍可被发现）
  - **Active**（手指按住）：透明度 100%，底盘轻微放大 1.05
  - **Limit**（转到仰角极限）：描边变浅灰 + 一次轻微回弹（告诉玩家"到头了"）

**摆放要求**：盘心距屏幕左右边缘各 90px、距底边 120px；**中间 400px 宽是净区**，坯体只占这块。

**触摸规则（三条，必须实现）**
1. **热区优先于刮削判定**：手指落在 180px 热区内，一律当"转动"，不触发刮削
2. **拖出圈外仍跟手**：手指从盘内拖到盘外，旋转继续生效直到抬手（否则最多只能转半圈，够不到 360°）
3. **抬手即停**：不做惯性拖尾。玩家要的是"转到哪个角度就停在哪个角度"

**灵敏度**：`0.55°/px`（拖 650px ≈ 转一整圈）。因为可以拖出圈外继续拖，屏幕大小不构成旋转上限。

**两个盘互斥**：同一时刻只有一个盘生效（后按下的接管），先按的自动失效。

**利手设置**：设置里提供"双盘 / 仅左 / 仅右"三档，默认**双盘**。
- 默认双盘 = 发现性最好，玩家自然用自己惯用的那只手
- 左利手可选"仅左"，右利手可选"仅右"，减少一个盘的视觉干扰
- **不要默认只显示一个**：新玩家看不到另一个盘，会以为只能单手、或不知道还能换手

**双指操作一律不响应**：两指同时按下时，既不旋转也不刮削。

## 5. Figma 高效工作习惯（单人重点）

1. 全部使用 Auto Layout，改文字自动撑开
2. 所有组件放一个【Components】页；参考图、AI 生成图放【Reference】页
3. 命名与文档统一：`ui_btn_main_workshop`、`ui_tab_dessert`
4. 导出：PNG / WebP，@2x，勾选透明背景
5. 导出后丢进 Cocos，统一打进 SpriteAtlas
