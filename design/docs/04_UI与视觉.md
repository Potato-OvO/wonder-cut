- **刮削页**：坯体占中间净区约 70%；左下/右下双触控盘；左上进度环、右上返回钮、底部工具栏。

## 2. 页面清单

### 2.1 大厅首页（启动页）

- 顶部：游戏 logo + slogan
- 中间**唯一主按钮：【惊喜工坊】**（V1.0 不出现【自由沙盒】入口）
- 次级入口：图鉴收藏室｜工具台｜设置
- 设置：音量开关、震动开关、**触控盘位置（双盘 / 仅左 / 仅右）**、清除缓存
- **中央 mascot（Q6 已纳入 V1.0）**：卡通环形修坯刀笑脸形象，站在圆形层叠展台中央，左右各一盆绿植；造型、配色与位置以样张 `sample2a_大厅首页_v12.png` 为准

### 2.2 盲盒抽取页（惊喜工坊入口）

- 池列表：常驻甜品工坊 / 常驻深海秘境 / 季节限定池，显示每池收集进度（已收集/总数/**还差 X 款**）与"限定"角标
- 不锁池，可随时切换；同时在线池最多 4 个
- 选中池后展示池预览、概率说明、抽卡按钮；"还差 X 款"用水印式小字提示（不弹窗、不催促）
- 显示星光币数量、今日免费抽取标记；抽取券通用

### 2.3 坯体操作主页面（核心游戏页）

- 85% 区域：立体坯全屏 3D 操作区（相机绕坯体 orbit）
- **左右两个触控盘（功能完全相同，都是 2 轴自由转动）**：分别放左下、右下，视觉直径约 140px（热区 180px）、半透明、按住才显形。拖向哪个方向，坯体就往那个方向转；**抬手就停在当前角度**，没有惯性拖尾。两盘只是位置不同，方便左手或右手单手操作，**全程不需要双指**
- 底部可收起悬浮工具栏：切换刀具｜重置坯体｜一键回正
- 左上角：中性进度环（已削体积/初始体积），无分数、无颜色警示
- 核心腔挖开后出现【收工】按钮，其余时间不显示
- 右上角：返回大厅按钮
- **触控分区**：落在触控盘热区 = 转动坯体；落在坯体上 = 刮削；落在空白 = 无响应（不误刮）
- **拖出圈外仍跟手**：手指从盘内拖到盘外，旋转继续生效，直到抬手为止
- 刀头落点偏移：手指会挡住落点，刀头显示在手指上方约 40px 处，保证看得见挖在哪

### 2.4 图鉴收藏室页面

- 分册 Tab：常驻册（甜品/深海）｜年度限定册，完成度分别计算
- 套装分组 Tab，陈列收集到的隐藏摆件
- 点亮/灰色未解锁区分，点击藏品重新把玩坯体（重温不产出星光币）
- 套装完成进度条

### 2.5 自由沙盒配置页（V1.1 上线，V1.0 不做、不展示）

- 材质选择、配色选择、坯体形状、模式切换【有限层数 / 无限漫游】

### 4.8 组件 8：双触控盘（**核心交互组件**）

> **两个盘功能完全相同**，不是"左管水平、右管俯仰"。每个盘都是 **2 轴自由转动**：拖向任意方向，坯体就往那个方向转。放两个只是为了让左手或右手都能单手操作，**不需要双指**。

- 尺寸：视觉直径 140px，热区直径 180px（热区比视觉大，好按）
- 图层（从上到下）：
  1. 底盘：圆形，填充 `rgba(216,194,174,0.35)`，1px 描边 `rgba(74,64,64,0.15)`
  2. 方向指示环：一圈细环，拖动时环上出现**偏移的小光点**，指示当前拖动方向与幅度（回中即复位）
  3. 中心握把：小圆点，primary_pink
- 状态变体：
  - **Idle**：整体透明度 30%（几乎不挡画面，但仍可被发现）
  - **Active**（手指按住）：透明度 100%，底盘轻微放大 1.05
  - **Limit**（转到仰角极限）：描边变浅灰 + 一次轻微回弹（告诉玩家"到头了"）

**摆放要求**：盘心距屏幕左右边缘各 90px、距底边 120px；**中间 400px 宽是净区**，坯体只占这块。

**触摸规则（三条，必须实现）**
1. **热区优先于刮削判定**：手指落在 180px 热区内，一律当"转动"，不触发刮削
2. **拖出圈外仍跟手**：手指从盘内拖到盘外，旋转继续生效直到抬手（否则最多只能转半圈，够不到 360°）
3. **抬手即停**：不做惯性拖尾。玩家要的是"转到哪个角度就停在哪个角度"

**灵敏度**：`0.55°/px`（拖 650px ≈ 转一整圈）。因为可以拖出圈外继续拖，屏幕大小不构成旋转上限。

**两个盘互斥**：同一时刻只有一个盘生效（后按下的接管），先按的自动失效。

**利手设置**：设置里提供"双盘 / 仅左 / 仅右"三档，默认**双盘**。
- 默认双盘 = 发现性最好，玩家自然用自己惯用的那只手
- 左利手可选"仅左"，右利手可选"仅右"，减少一个盘的视觉干扰
- **不要默认只显示一个**：新玩家看不到另一个盘，会以为只能单手、或不知道还能换手

**双指操作一律不响应**：两指同时按下时，既不旋转也不刮削。

## 5. Figma 高效工作习惯（单人重点）

1. 全部使用 Auto Layout，改文字自动撑开
2. 所有组件放一个【Components】页；参考图、AI 生成图放【Reference】页
3. 命名与文档统一：`ui_btn_main_workshop`、`ui_tab_dessert`
4. 导出：PNG / WebP，@2x，勾选透明背景
5. 导出后丢进 Cocos，统一打进 SpriteAtlas
