# 08 · 素材制作指南（参考）

> **状态**：⚪ **参考**——不是规格，AI **不要**据此写代码。
> **读者**：你自己（出美术/音频素材时看）
> **相关**：`03_内容与资产.md`（交付清单与规格）、`04_UI与视觉.md`（视觉令牌）

> 核心思路：**优先低成本工具、AI 辅助、减少手绘负担、统一画风。不要追求专业商用美术水准，干净柔和即可。**

---

## 1. 推荐工具

### 1.1 绘图（三选一）

1. **Figma（强烈推荐，免费网页版）**：UI、按钮、图标、logo、分享卡片、双触控盘。矢量，改尺寸无损，导出 PNG/WebP
2. **Procreate（iPad）**：手绘材质贴图、夹层纹理，质感最好
3. **Krita（电脑免费开源）**：替代 PS，画可平铺材质贴图

> 不推荐 PS，太重；优先 Figma 搞定全部 UI。

### 1.2 3D 工具

1. **Blender（免费）**：只在精修隐藏物低模时用。**坯体不需要建模**
2. **图生 3D 工具（Meshy 等）**：隐藏物主力路线——出干净正面图 → 图生模型 → 减面 → 导出 GLB
3. **基础几何拼装**：球/柱/环/锥组合 + 倒角，够用且零成本，**优先于上面两条**

> 记住：**坯体是参数化的，不建模**。3D 工具只为 16 个隐藏物服务，不要过度投入。

### 1.3 AI 辅助

- 文生图：Midjourney / 豆包生图 / Stable Diffusion
- **用途 1（材质）**：生成**可平铺的材质纹理**，再修成无缝平铺、统一色调
- **用途 2（隐藏物）**：生成"单个物体、纯白底、正交视角"的干净参考图，再丢进图生 3D 转 GLB

**提示词模板（直接复制）**

> 【材质】`seamless tileable PBR texture, pastel macaron soft color, matte smooth surface, flat even lighting, no shadow, no outline, top-down orthographic, high detail micro texture, soft aesthetic, no text, no watermark`
> 【隐藏物】`single cute miniature object, pastel macaron soft color, matte smooth surface, isolated on plain white background, 3d render, clean silhouette, game prop, no text, no watermark`

> ⚠ **不要再生成"透明底的单体坯贴图"**——立体坯不需要它，而且用了会让造型和贴图对不上。

### 1.4 音效

1. **Freesound.org**（免费，注意看 CC0 无版权）
2. **剪映**（自带 ASMR 素材，导出 mp3）
3. **Audacity**（免费：剪辑、降噪、调音量）

### 1.5 粒子贴图

直接在 Figma 画简单圆形、星光、圆点、渐变光斑，导出透明 PNG，不用复杂手绘。

## 2. 制作顺序（**必须按这个顺序，避免卡住**）

```text
UI 基础组件 → 坯体造型配方（调参，不画图）→ 材质贴图 → 隐藏物 3D 低模
  → 夹层纹理 → 刀具图标 → 粒子贴图 → 音效
```

理由：程序先搭框架，你先把按钮、图标做完，程序可以先拼页面；再做核心玩法的坯和隐藏物。

> **顺序变了**：坯体不再"画贴图"，而是"调造型参数 + 画一张材质贴图"。调参可以在程序做完 voxel 核心之后立刻开始，比原来更早能进内容。

> ⚠ **在视觉令牌锁定前，只出草稿，不要批量出图**（见 `00_状态与决策.md` §2）。

## 3. UI 怎么做（马卡龙柔光极简，你的重点）

### 3.1 统一规范（固定，后面所有 UI 遵守）

- 圆角：大按钮 24px，小图标按钮 12px
- 配色（低饱和，治愈）
  - 主粉 `#F9D8E4`｜主蓝 `#C7E6F6`｜薄荷绿 `#D6F4E7`
  - 文字 `#444444`（深灰，不要纯黑，刺眼）
  - 蒙版面板：白色 75% 透明度 + 一点高斯模糊
- 阴影：非常柔和、低透明度，不要硬黑阴影
- **禁止高饱和刺眼颜色**——解压游戏，柔和第一位

### 3.2 Figma 做 UI 步骤

1. 新建画布，2x 分辨率（750 宽基准，微信小游戏标准竖版）
2. 先建立**组件库**：按钮、开关、Tab，后面复制复用
3. 按钮两态：Normal / Pressed（明度稍暗，不要大变）
4. 图标全部用线性+填充柔和图标，线条粗细统一 2.5px
5. 做完一组选中 → 导出 PNG，勾选透明背景
6. 导入 Cocos，打 SpriteAtlas

> 偷懒技巧：图标不要从零画，Figma 插件「Iconify」里有大量免费柔和图标，改色即可。

## 4. 坯体怎么做（**造型配方 + 材质贴图，不建模、不画轮廓**）

> ⚠ 坯体是**立体**的，由程序按"造型配方"在运行时生成几何。你不画轮廓、不做模型，只做两件事：**调造型参数** + **画一张材质贴图**。

### 4.1 造型配方怎么调（新的"美术活"）

1. 每个坯 = `primitives`（roundBox / sphere / cylinder / cone，**可多个**）+ `ops`（smin 平滑并集 / subtract 减去 / shear·bend·twist·scale 变形）+ `noise`
2. 调参口诀：**先定体块关系（几块怎么拼）→ 再定胖瘦（size）→ 再定圆角（radius）→ 再加减法做缺角/凹陷 → 最后加噪声（0.5~1.5mm）**
3. **四个维度做差异**（都在"粗壮"范围内，够出 16 款完全不同的坯）：
   - **体块关系**：单体 / 双体融合 / 球+锥 / 球减球（碗）/ 半球
   - **变形**：剪切（歪）、弯曲（弯）、压扁（扁）、扭转（旋）
   - **表面**：噪声起伏、小球凸起、凹坑
   - **比例**：扁 vs 高 vs 矮胖
4. **必须过的体检（脚本自动跑，不过就改参数）**
   - 最小局部厚度 **≥10mm**（低于这个，刮两下就断成孤岛）
   - 连接处（颈/腰）**≥10mm**
   - 体素占用率 35%~70%
   - 最大内切球半径 **≥12mm**（保证放得下核心腔）
   - 单连通（不许碎成两块）
   - 尖端圆化半径 ≥3 体素
5. **"粗壮的不规整可以，纤细的不规整不行"**
   - ✅ 可以：歪、缺角、扁/鼓、表面凹凸、噪声起伏、葫芦形、半球伞盖、碗、螺旋
   - ❌ 不行：细长触角/鹿角、薄片/翼/鳍、细颈、镂空环、尖刺、多分支
   - 想要"尖"（如甜筒底）→ **圆化收口**：锥收到 10mm 圆头，观感仍然是"锥"
6. 每款坯的造型差异要**一眼可辨**：盲盒的第一层惊喜是"这个坯长得不一样"，16 款长得像 16 个圆角盒，期待感就废了一半

### 4.2 材质贴图怎么画（512×512；传说款 1024×1024）

1. 思路：**先 AI 生成参考图，再修图、统一色调、做成可平铺的无缝贴图**
2. 风格：哑光、柔和、干净，**不要强烈光影**（光影由引擎打，贴图里带光影会脏）
3. 材质差异：
   - 动力沙：柔和杂点颗粒纹理
   - 冷制皂：细腻均匀，轻微磨砂
   - 果冻：半透明通透渐变（配 alpha 与高透）
   - 奶油蜡：丝滑渐变，几乎没有噪点
4. **一张贴图要同时表达"外表"和"切面"两种质感**（必做）
   - 外表：更光滑、亮一点、颗粒细
   - 切面：更哑光、略深、颗粒更粗、有细密拉丝痕
   - 做法：1 张 baseColor + 1 张法线/粗糙度，程序按 `originDist`（挖深）在两者之间插值。**不要交两套贴图**
5. **配色只交 1 张中性色底图**：明度居中、饱和度低。3 色变体由 shader 生成

> 避坑：不要硬黑描边；不要放复杂构图（坯被反复切削，细节太碎切完就糊）；**不要画"轮廓/描边/阴影"**，那些在立体坯上全是错的。

## 5. 隐藏物 3D 低模

- 隐藏物是**实心 3D 物体**，玩家挖到就停，不会被刮碎
- 规格：普通/稀有 ≤1500 面，史诗 ≤2500 面，传说 ≤4000 面；导出 GLB（可 Draco）
- 传说款额外多一张**发光遮罩贴图**（256 单通道）：白色渐变，用于自发光
- **尺寸**：直径不小于坯体最短边的 25%，太小挖出来没存在感
- 单人省事做法（按优先级）：
  1. **基础几何拼装**（球/柱/环/锥 + 倒角）——够用且零成本
  2. **AI 图生 3D**（Meshy 等），出来再减面
  3. 最后才考虑手搓 Blender

> ⚠ **不要为单个隐藏物卡超过半天**。它是"揭晓奖励"，不是主角——主角是坯体和刮削手感。

## 6. 刀具图标、粒子贴图

- 刀具：256×256，透明底，简约扁平
- 粒子：
  - 沙粒：小圆点，浅棕
  - 果冻水珠：淡蓝渐变圆
  - 星光：四角星/十字柔光光斑
  - 金币：小圆渐变黄色

> 粒子尽量简单！粒子太多、贴图复杂，微信低端机直接卡。

## 7. 音效制作与版权（单人最容易踩坑）

- ✅ 优先 **CC0 免费无版权**素材（Freesound），商用没问题
- ❌ **不要**直接拿抖音、B 站的 ASMR 音频，有版权风险

操作：
1. 下载原始音频
2. Audacity 降噪、剪掉爆音、统一音量
3. 导出 mp3：44.1kHz、**单声道 64kbps**
4. 分类命名：`audio_material_sand_slow.mp3`

---

## 8. 单人美术偷懒策略（**非常重要，防止被美术拖垮**）

1. **同材质复用纹理**：8 个动力沙坯共用同一张沙子噪点材质贴图，只调颜色
2. **造型靠参数复用**：同系列坯用同一个基础体，只改 size / radius / noise seed，10 分钟出一款
3. **夹层纹理全局复用**：糖粒、闪粉只做一张，多个坯共用
4. **隐藏物优先少而精**：重点打磨 4 个传说隐藏物（买量镜头），普通隐藏物用基础几何拼装
5. **粒子贴图全部复用**，只改颜色
6. **卷片 mesh 只做 4~6 个变体**，靠缩放/弯曲/颜色复用
7. 前期版本可以**不带复杂光效**，V1.0 先保证玩法跑通

---

## 9. Cocos 导入设置（必做，否则包体大、糊）

- 压缩格式：**ETC2**
- **材质贴图开启 mipmap**（3D 物体远近都需要，关了会闪烁）
- 过滤模式：Bilinear
- 图集：UI 打 SpriteAtlas；**材质贴图不进 UI 图集**
- 隐藏物 GLB：导入后**减面 + 开启 Draco**，检查面数是否符合规格
- **三平面材质**：材质贴图要设为 **Repeat（可平铺）**，因为三平面投影会重复采样

## 10. 画风自检清单（画完一张对照）

- [ ] 整体低饱和柔和，没有刺眼大红大绿
- [ ] 没有厚重黑色描边（立体坯上描边是错的）
- [ ] 贴图可无缝平铺，接缝看不出来
- [ ] **同一张图能表达"外表光滑"和"切面哑光"两种质感**
- [ ] 尺寸符合规范，不超上限
- [ ] 文件名按命名规范，方便管理
- [ ] 隐藏物：面数达标、直径 ≥ 坯体最短边 25%、能一眼认出是什么
