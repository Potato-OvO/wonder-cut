# 一、买量短视频脚本（15s，广点通投放，竖版 9:16）

> 全部瞄准传说坯高光镜头，开头 3s 抓眼球，结尾引导点击小程序。
> **拍摄口径（3D 版）**：全程是"手里托着一块立体坯在转着削"，不是平面特写。**前 3 秒必须出现"卷片成条飞出去"和"边缘扇贝状"**——这两样是平面小游戏做不出来的，也是最抓人的。

## 脚本 1｜沉船宝藏款（爆发力强，适合泛流量）

| 时间 | 画面 | 声音 |
|---|---|---|
| 0-3s（钩子） | 环形修坯刀插进深棕色沙块，手腕一拧，一条厚卷片整条卷着飞出去，镜头跟着卷片甩一下 | 配音（轻快女声）：这个沙块里面，居然藏着宝藏？ |
| 3-10s（过程） | 镜头绕坯体转半圈（展示立体），连续几刀刮出扇贝状边缘，凹槽一层层加深，慢慢露出宝箱边角 | 清晰 ASMR 沙沙声 + 卷片剥离的"啵" |
| 10-14s（高光） | 宝箱完全露出，慢镜头，金币粒子炸开，光效拉满，坯体在手里慢慢转 | 配音：哇！挖到传说宝箱啦！ |
| 14-15s（引导） | 弹出 logo【奇妙切割工坊】，按钮：点击来挖宝藏 | 配音：快来一起切割解锁惊喜！ |

## 脚本 2｜荧光水母款（治愈安静向，女性流量）

- **0-3s**：半透明果冻坯在手里慢慢转，环形刀轻轻削下一片薄薄的透明卷，边缘微微回弹 → 配音："切开这个果冻，看看里面藏了什么？"
- **3-10s**：转着削，凹槽里的光透过果冻折射，通透质感，咕叽 ASMR 音效
- **10-14s**：夜光水母浮现，柔和自发光粒子缓缓飘散，慢镜头 → 配音："是夜光水母，也太治愈了！"
- **14-15s**：logo 弹出，点击小程序解锁更多惊喜

## 脚本 3｜海盐冰淇淋甜筒（甜品向，高转化）

- **0-3s**：冰淇淋造型的立体沙坯（不规则球体 + 底部锥形），环形刀挖出一长条奶油色卷条，卷条垂下来 → 配音："这个冰淇淋里面藏着小秘密！"
- **3-10s**：转着削，一勺勺挖出圆润凹槽，卷条不断掉落堆在桌上
- **10-14s**：迷你甜筒雕塑完整露出，星光粒子 → 配音："传说款甜筒！"
- **14-15s**：点击进入，盲盒切割解锁

> **剪辑备注**：全程保留 ASMR 原声，BGM 音量压低，高光镜头加慢放。
> **禁止出现的画面**：一张平面贴图在屏幕上平移/缩放——那会暴露这是 2D，直接毁掉立体感。

# 三、V1.0 宣传口径（**必须遵守**）

- V1.0 **只主打主线（惊喜工坊）**，并把主线作为唯一宣传点
- **禁用词**：放空模式、无目标玩法、双模式、随时切换沙盒、自由沙盒
  → 这些是 V1.1b 之后才成立的承诺，V1.0 说了就是货不对板
- **必须突出**：立体坯、转着削、弧形凹槽、扇贝状边缘、卷片成条飞出、盲盒惊喜
- **不要出现**：平面贴图式的平移/缩放画面
