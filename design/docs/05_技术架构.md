## 1. 技术路线（已定，不许换）

**体素 SDF 减材 + 局部 Marching Cubes 重建。**

一句话：坯体是"一坨密度场"，刀是一个球头，削 = 在密度场上做减法，削完把脏掉的那一块重新生成三角面。

### 1.1 为什么不用其他方案

| 方案 | 为什么否决 |
|---|---|
| 2D 遮罩侵蚀（旧方案） | 没有厚度、没有凹槽、削不出卷片，参考图的三样核心一个都做不了 |
| GPU raymarching（SDF 直接画） | 填充率在微信低端机上不可控；全屏步进 40~64 步 × 540×960 是自杀 |
| 多边形布尔 / 物理碎片 | CPU 必炸，低端机 100% 卡死 |
| **体素 + MC 局部重建（选它）** | 三角面数量由**表面积**决定（约 8k~20k），不由体积决定；渲染是普通网格，光照/阴影/材质全部白送；拾取用 CPU 光线步进，不需要物理引擎 |

### 2.1 依赖方向（单向，不许反向）

```text
ui ──→ game ──→ core
platform ←─ game / ui      （platform 只被调用，不调用别人）
```

**分层铁律**
- `core/` **不许** import `cc`（除类型），**不许**碰节点/渲染/音频
- `core/` 不自己读 config 文件，**通过参数接收**注入的配置
- `ui/` 只负责展示与输入，**不许**写玩法规则
- `platform/` 只封装微信 API，**不许**写业务判断
- `game/` 是唯一的编排层，它同时知道 core 与 platform

## 4. 数据层

三层，全部是普通数组，没有引擎黑魔法。

### 4.1 密度场 `density`

- `Uint8Array(grid³)`，0 = 空，255 = 满
- 48³ = 110,592 字节 ≈ **108KB**
- 低配降到 32³（32,768 字节）；传说/异形可到 56³（175,616 字节）
- 分辨率按坯分档：`voxel.gridNormal / gridEpic / gridLegend / gridLowSpec`
- **必须用 `Uint8Array`**，不用 `Float32Array`（体积 1/4，且 DDA 步进全是整数比较）

### 4.2 原始距离场 `originDist`

- 同尺寸 `Uint8Array`，记录"每个体素到**初始表面**的距离"（归一化 0~255）
- **这个数组在刮削中永不修改**——它是"挖了多深"的唯一依据
- 用途：三层色带、深度分档、进度环、薄处削深调制，全部变成一次数组查询，**零额外计算**

### 4.3 埋藏腔表

- `[{x, y, z, radiusMm, tier}]`，开局生成后**冻结**，与密度场完全解耦（腔位不会被刮跑）

## 5. 几何生成（坯体零模型资产）

1. **造型配方**：`primitives`（roundBox / sphere / cylinder / cone，可多个）+ `ops`（smin / subtract / shear·bend·twist·scale）+ `noise`
2. 开局把 SDF 采样进 `density`（一次，约 10~30ms，放在加载动画里）
3. 同时算一次 `originDist`（三维距离变换，约 20~40ms）
4. 两件事都只在开局做一次，**运行时不再全量重算**
5. 采样后必须跑**造型体检**（厚度/单连通/占用率/内切球），不过的配方不许进包

> 造型约束见 `03_内容与资产.md` §5.1 与 `AGENTS.md` §3.5。

## 6. 减材（笔刷）

```text
每帧拿到手指位移 → 投影成一条从相机出发的射线
射线在 density 上做 DDA 步进，找到第一个"实体表面"命中点 P（最多 ~120 步，纯整数运算）
以 P 为中心、刀头半径 R 为半径，把球内体素密度按材质参数削减（不是直接置 0，按"削深"衰减）
把受影响区域的 chunk 标记为 dirty
```

### 6.1 刀头形状

| 刀具 | 形状 | 效果 |
|---|---|---|
| 环形修坯刀 | 球头 | 挖出弧面凹槽（主推） |
| 细线切割器 | 胶囊/细圆柱 | 窄而深 |
| 齿纹刀 | 球头 + 表面正弦扰动 | 凹槽带齿纹 |
| 碎锤 | 大半径 | 击碎 |

### 6.2 宽扫 vs 深钻

只是 `headRadiusMm` 和"单帧削减量"两组参数，**不是两套逻辑**。

### 6.3 薄处削深调制（**必须做**）

```text
实际削深 = min(刀头削深, 局部厚度 × 0.6)
```

- 局部厚度直接读 `originDist`（2 × 距离值），零额外开销
- **不做这条的后果**：薄处一刀穿透（刀头削掉的是固定半径的球），玩家会感觉"莫名挖穿"，破坏"可控"的解压感
- **做了这条的后果**：薄处自然变"刮得浅、刮得慢"，厚处正常——这反而是好的手感层次

### 6.4 材质差异

| 材质 | 减材行为 |
|---|---|
| 动力沙 | 削得慢但连续 |
| 冷制皂 | 削得快，边缘按概率崩缺 |
| 果冻皂 | 削后缓慢回弹（把削掉的密度**部分还原**） |
| 奶油蜡 | 最顺滑，内壁最光滑 |

## 7. 渲染（局部重建，性能关键）

1. 把密度场切成 **`chunkDivisions`（默认 6）个"大块"**，每块一个 `MeshRenderer`
2. 只有被笔刷碰到的块才重算 Marching Cubes，并**只重传这一块的 vertex/index buffer**
3. 单块重建目标 **<3ms**；一帧最多重建 `maxRebuildPerFrame`（默认 2）块，其余排队到下一帧（削的时候人眼看不出 1~2 帧延迟）
4. 顶点属性只保留 `position + normal + 一个"深度"标量`；**不做 UV**，材质走**三平面投影（triplanar）**
   - 三平面：按法线主轴混合 3 次采样，任意造型都不需要 UV 展开，正好配合"形状任意"
5. 切面着色：`color = f(originDist)` → 三层色带 + 凹槽底部压暗；再叠一层"切面比外表更哑光"的 roughness 差异

## 8. 拾取与旋转

### 8.1 拾取

**不用物理引擎**：CPU 对 `density` 做 DDA 光线步进，比三角面 raycast 更便宜也更准（还能顺便判断"这一刀挖到多深"）。

### 8.2 旋转 = 相机 orbit（不是转物体）

原因：笔刷永远在世界空间，**转走再转回痕迹天然保留**，不需要任何坐标系转换。

### 8.3 双触控盘（规格见 `AGENTS.md` §3.4）

- **两个盘功能完全相同**，每个都是 2 轴自由转动（水平拖动→方位角，垂直拖动→仰角）
- **必须分轴映射**：水平拖只改方位角、垂直拖只改仰角
- **不要做成 arcball/trackball**（拖拽方向决定旋转轴）——arcball 会引入 roll，物体"歪着转"，玩家会晕
- 方位角不限（360°），仰角限制 ±85°
- **抬手即停，无惯性拖尾**；`roll` 锁死
- 灵敏度约 0.55°/px，且**拖出盘外仍继续跟手**（否则最多只能转 77°，够不到一圈）
- **不做双指操作**；"一键回正" = 相机插值回初始角度

## 9. 卷片（ASMR 主音画）

- 预制 4~6 个"弯曲带条" mesh（宽 8~20mm、厚 2~4mm、长 40~120mm，带一点弯曲）
- 每刀按刀速生成 1~3 条：从命中点沿刀路方向飞出，带自旋 + 抛物线 + 落地堆叠
- **对象池复用**，同屏上限 24 条（低配 8 条），超上限回收最旧的
- 材质参数决定卷片形态：动力沙宽厚带沙粒｜冷皂短且易断｜果冻薄且会塌｜奶油蜡超长连续

## 10. 性能预算与避坑清单

### 10.1 硬指标

| 指标 | 目标 |
|---|---|
| 低端安卓帧率 | 连续刮削 **≥30fps** |
| 单块重建 | **<3ms** |
| 每帧重建块数 | **≤2** |
| 密度场内存 | <1MB，整局不增长 |
| 整包 | **≤13MB** |

### 10.2 必须做

- ✅ 密度场用 `Uint8Array`，DDA 步进全整数比较
- ✅ **只重建脏块**，绝不整场重建
- ✅ 顶点属性砍到最小（position + normal + 1 个标量），不传 UV、不传切线
- ✅ 卷片、碎粒、闪粉、金币粒子全部对象池复用
- ✅ 三平面采样用 `texture2D` 3 次 + 一次法线权重，不要写循环
- ✅ 关闭不必要的后处理：只保留简单柔光，不开 bloom 高配；做高低配画质开关
- ✅ 贴图压缩 ETC2，单张 ≤1024×1024
- ✅ 震动控制：短震动，不要持续高频，iOS 有调用频次限制
- ✅ 资源懒加载：图鉴、套装资源分包加载
- ✅ **重建期间不 GC**：预分配所有 buffer，重建只写不建

### 10.3 绝对禁止

- ❌ 不要用 Box2D/物理引擎做碎片模拟
- ❌ **不要用 GPU raymarching 画坯体**
- ❌ 不要做多边形布尔（Clipper/CSG）逐笔求交
- ❌ 不要每帧重建整块 mesh（20k 顶点全量上传 = 每秒几十 MB，必掉帧）
- ❌ **不要在触摸回调里做重建**：重建统一在 `lateUpdate` 的 dirty 队列里做，避免一帧重建多次
- ❌ **不要从 RenderTexture 回读像素做判定**：微信端不可靠且极慢

## 11. 兼容与降级

- 【低配模式】开关：密度场降 32³、卷片降到 8 条、关闭粒子与慢镜头
- **分辨率按坯分档**：普通/稀有 40³，史诗 48³，传说 56³——把算力花在买量镜头上
- 测试重点：安卓低端机（骁龙 6xx 及以下）、微信 iOS 端

### 11.1 降级方案（阶段0 Gate 不过时启用）

若体素方案在低端机跑不到 30fps，退到**多层同心壳侵蚀**：

- 3~4 层同心壳，擦 UV 露下一层
- 视觉弱一档（洞是平洞、没有凹槽），但能保上线
- 触控盘、腔位、色带、结算逻辑全部不变，只换渲染层

> 这是**保上线**方案，不是首选。详见 `07_验收与排期.md` 阶段0 Gate。

## 12. 阶段0 Spike（先验证，别急着做美术）

| # | 任务 | 通过标准 |
|---|---|---|
| 0-1 | 程序化 SDF → 密度场 → 全量 MC 重建 → 渲染 | 能看见坯体 |
| 0-2 | 笔刷减材 + 脏块局部重建 | 单块 <3ms |
| 0-3 | DDA 拾取 + orbit 相机 + 双触控盘 + 触控分区 | 能转能刮 |
| 0-4 | 异形坯试刮（缺角+噪声） | 不破面、薄处不穿透 |
| 0-5 | 色带着色 + 卷片飞出 + 音效触发 | 样片能看出四件事 |
| 0-6 | 低端安卓真机实测 | ≥30fps |

**Gate（三条全过才进阶段1）**
1. 低端安卓真机 **≥30fps**（连续刮削 60 秒不掉帧、不闪退）
2. 单块重建 **<3ms**，且连续刮削时**没有 GC 卡顿**
3. 样片能看出"立体、凹槽、扇贝边、卷片"四件事，**且异形坯不破面**

> 任一不通过 → 走 §11.1 降级方案，不要硬扛体素。
