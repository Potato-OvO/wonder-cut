## 4. 决策日志（防止反复推翻）

| 日期 | 决策 | 理由 |
|---|---|---|
| 2026-11-11 | **坯体从 2D 贴图改为 3D 体素减材**（R2 路线） | 2D 遮罩给不了"厚度、弧形凹槽、卷片"三样，而这三样正是参考图的核心吸引力 |
| 2026-11-11 | 不做 GPU raymarching，用 MC 动态网格 | raymarching 在微信低端机填充率不可控 |
| 2026-11-11 | 旋转用**左右两个功能完全相同的 2 轴触控盘** | 单手可操作，不需要双指；2 轴输入天然覆盖所有可见面 |
| 2026-11-11 | **仰角限制 ±85°，不做全向翻滚** | 允许翻到底朝天会让玩家迷失上下 |
| 2026-11-11 | **彻底不做双指操作** | 避免与刮削抢触摸，也避免玩家误以为要两指 |
| 2026-11-11 | **抬手即停，不加惯性** | 玩家要"转到哪个角度就停在哪个角度"，惯性会让每次定位多等半秒 |
| 2026-11-11 | 分轴映射，**不用 arcball** | arcball 会引入 roll，物体"歪着转"，玩家会晕 |
| 2026-11-11 | 造型"**粗壮的不规整可以，纤细的不规整不行**" | 体素分辨率 + 刀头半径的物理限制，不是审美偏好 |
| 2026-11-11 | 浇筑环节**移到 V1.1** | V1.0 不放一个可以跳过的空仪式；配色变体改为抽取时随机，不依赖浇筑 |
| 2026-11-11 | 默认主刀改为**环形修坯刀** | 参考图同款，凹槽与扇贝边是它的天然产物 |
| 2026-11-11 | 隐藏物从 2D 贴图改为 **3D 低模** | 立体坯里放一张平面贴图会穿帮 |
| 2026-11-11 | 文档拆分为多份 + `AGENTS.md` 作为 AI 入口 | 单文件 1847 行混了 4 类权威等级不同的内容，无法标记状态 |
| 2026-11-11 | 数值单一来源：只放 `design/config/config.json` | 避免 md 与 JSON 各写一遍导致漂移 |
| 2026-11-11 | **视觉底色由纯白/浅马卡龙改为中明度暖灰褐系** | 纯白底 + 低饱和 + 弱阴影在手机上大面积高亮晃眼；样张确认背景 `#B8AAA3` 系、主粉改豆沙粉 `#E5B7C6`，初始浅马卡龙色值作废 |
| 2026-11-11 | **光照定为柔和漫射 + 轻微明暗过渡，禁止方向强光/镜面高光/纯白底** | 单主光导致左半过曝；全平涂又缺视觉落点；批量出图话术与禁用清单见 `04` §0.3 |
| 2026-11-11 | **生图材质描述禁用"哑光/高光/稍亮/粗糙度"等矛盾词** | 模型对哑光理解不稳定，会出泡沫孔状表面；材质光泽交给引擎粗糙度参数控制，样张只描述压实沙质本身 |
| 2026-11-11 | **大厅 mascot、圆形展台与左右盆栽纳入 V1.0** | 样张形象定稿，作为大厅中央固定装饰写入 04 §2.1，后续大厅出图按此复用 |
| 2026-11-11 | **隐藏物保留珠光/虹彩质感** | 结算卡彩虹摆件效果定稿；珠光由引擎材质珍珠光泽参数表现，不做釉面高光或塑料反光 |
| 2026-11-11 | **UI 渲染语言确认为「平涂」**（令牌原值），修正首批样张的 3D 黏土漂移 | 平涂可用 Sprite + 9-slice 任意拉伸；黏土有固定厚度与光照方向、无法 9-slice，每个尺寸都要单独出图，包体与工时翻倍 |
| 2026-11-11 | 生图引入**定妆图锚点**：每款坯先出 1 张定妆图，其余图必须垫图（image-to-image 0.55~0.70） | 首批 4 张纯文生图，导致同款坯出现方墩/圆台/软团三种形态 |
| 2026-11-11 | 生图**禁止画面内出现文字**，文字后期在 Figma / Cocos 叠 | AI 生中文必乱码（首批 2a 副标题即为乱码伪文字） |
| 2026-11-11 | 文档结构改为 `design/` + `tools/` 双树，`AGENTS.md` 留在仓库根 | 文档与代码分开；AI 工具只自动读根目录的 AGENTS.md |
| 2026-11-11 | **初始化 git 仓库**（`main` 分支，首提交 `aaa8ec7`） | 无版本控制时 AI 批量改文件没有任何回滚点 |
