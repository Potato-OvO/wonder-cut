# 1. 项目概述
## 1.1 产品定位
一款无失败、无惩罚、低焦虑的ASMR**立体刮削**解压小游戏。
玩家手持**立体坯**（有厚度、有体积），用环形修坯刀、钢丝、锤子等工具**转着坯子削**：一勺勺挖出弧形凹槽，成片卷片卷起飞出，刮开盲盒坯，发掘内部随机隐藏摆件，获得视觉、听觉、震动多重感官治愈。
核心卖点：**盲盒惊喜 + 立体坯任意角度刮削 + 图鉴收集，不强制任务、无失败惩罚**。
> **V1.0 只做主线（惊喜工坊）并以主线作为唯一宣传点**。**大厅不出现【自由沙盒】入口，沙盒的 UI、配置页与控制器都不随 V1.0 发布**；自由沙盒（含有限层数 + 无限漫游）整体在 V1.1b 上线后，才作为第二卖点推出。
> **宣传口径（V1.0 阶段禁用词）**：不要出现"放空模式""无目标玩法""双模式""随时切换沙盒"——这些是 V1.1b 之后才成立的承诺，V1.0 说了就是货不对板。

## 1.2 目标用户
- 核心人群：16–38岁学生、上班族，喜欢ASMR、捏捏乐、解压短视频，碎片化消遣（午休、睡前、通勤间隙）
- 次要人群：喜欢收集、盲盒、可爱治愈物品的泛休闲玩家
- 排斥人群：追求竞技、闯关、高难度挑战的用户（本产品不服务这类用户）

## 1.3 核心差异化（对比市面上同类）
✅ **单点打法清晰**：V1.0 只主打"盲盒刮削主线"，宣传口径统一，不做双模式分流转化的赌博
✅ 自由选池：常驻与季节限定池随时切换，不锁池、不设顺序解锁
✅ 材质差异化：动力沙/冷制皂/果冻皂/奶油蜡，每一种材质手感、音效、破碎逻辑完全独立
✅ **立体真减材**：坯体是有厚度的立体块，可任意角度转动、从任意表面下刀，削出弧形凹槽与扇贝状边缘，削下来的卷片保持形状——平面贴图做不到这一层"厚"的手感，而"厚"正是这个品类的护城河
✅ 盲盒机制：外观一致，内部隐藏物随机，传说款自带慢镜头高光，天然适配买量短视频
✅ 零压力红线：无体力、无倒计时、无星级评分、无失败惩罚，砸碎坯体也有保底奖励
✅ 商业化克制：纯IAA仅自愿激励视频，无内购、无开屏、无自动插屏

## 1.4 游戏slogan
主标语：随心切割，解锁藏在里面的小惊喜
副标题：治愈ASMR，放松一刻

# 2. 核心玩法设计
## 2.1 模式规划（V1.0 只有主线）
> **V1.0 的大厅只展示【惊喜工坊】一个主入口，完全不做自由沙盒入口**（代码可预留，但 UI 不出现、宣传不提、买量素材只讲主线）。
> 自由沙盒（含"有限层数"与"无限漫游"）整体放到 V1.1 上线，作为第二个卖点推出。

### 模式A：惊喜工坊（主线，V1.0 唯一玩法，买量主打）
#### 核心循环：
自由选池抽坯 → 刮削切割（立体坯，双触控盘任意角度转动）→ 埋藏腔逐个揭晓 → 发放星光币/小物 → 星光币抽新坯/解锁套装工具 → 图鉴收录

```text
打开小游戏 → 大厅
  └─【惊喜工坊】
       ├─ 选池（自由切换，同时在线≤4；常驻 / 季节限定）
       ├─ 抽坯（每日免费 / 星光币 / 激励视频；概率 45/30/20/5）
       └─ 刮削主页面（立体坯，左右双触控盘任意角度转动）
            ├─ 体积减材：环形刀从任意表面下刀，削出弧形凹槽，坯体逐层变薄
            ├─ 埋藏腔 N=1~6（按体积与"距表面深度"生成）
            │     ├─ 核心腔（最深）：主藏品率随稀有度 40/45/50/60%
            │     └─ 小物腔：空腔60% ｜ 小物40%
            └─ 结束：自然揭晓 / 收工 / 砸碎 / 挖穿兜底
                 └─ 结算卡（星光币 + 小物 + 图鉴收录）→ 返回池列表
```
1. 盲盒抽取（自由选池，不锁池）
    - 玩家可在任意已上架池之间自由切换，不设顺序解锁；池列表显示每池收集进度
    - 每个池独立概率：普通45%｜稀有30%｜史诗20%｜传说5%；池与池之间概率一致，只有内容不同
    - 每日免费1抽；消耗星光币抽取；观看激励视频抽取（传说概率提升）
    - 抽取券通用：免费抽与视频抽可在任意已上架池使用，不绑定池
    - 同时在线池上限4个；季节限定池仅在活动期间开放
    - 同一款坯外表完全一样，内部埋藏腔布局随机，稀有度分为：普通✦ / 稀有✦✦ / 史诗✦✦✦ / 传说✦✦✦✦
2. 浇筑环节（**整体移到 V1.1，V1.0 不做**）
    > V1.0 的路线是"抽到坯直接刮"，不放一个可以跳过的空仪式。浇筑（挑色浆→倒模→按压脱模）作为 ASMR 前置互动，与配色系统一起在 V1.1 上线。
    - **V1.0 配色规则（不依赖浇筑）**：每款坯 1 种主色；抽取时按色变体取色（V1.1a 起 3 色），图鉴按"款"记录不重复计数，**分享卡按"色"生成**——同一款坯可以被玩家当成三个不同收藏品分享，相当于在不增加美术工期的前提下把感知内容量提升到 3 倍。
    - **V1.1 浇筑上线后**：玩家可主动选色浆决定本局配色（跳过则随机），浇筑成为完整的 ASMR 仪式。
    - **实现方式（硬约束）**：配色必须走**参数化调色（shader 色相偏移 + 明度/饱和度调整）**，材质只做 1 张中性色基底，**不新增贴图**。禁止"每色一张贴图"，否则材质贴图会从 0.5MB 涨到 2MB+。
3. 刮削切割（核心交互，立体减材）
    - 坯体是**真立体**：有厚度、有体积，可在**任意角度**转动。旋转用**左右两个触控盘**（左下、右下各一）：**两个盘功能完全相同**，都是"2 轴自由转动"——拖向哪个方向，坯体就往那个方向转；只是位置不同，方便左手或右手单手操作，**不需要双指**。手指按住拖动 = 转，**抬手就停在当前角度**（无惯性拖尾）；另保留"一键回正"兜底。刮削痕迹记录在体素空间内，转走再转回痕迹保留
    - **转到位再刮**是主节奏；但**左手按住触控盘转、右手同时刮**也是允许的——此时刀路固定在屏幕上、坯体在转，会自然削出一条连续螺旋切面，正是参考图"一手转坯一手削"的动作
    - 刮削采用**体积减材（体素雕刻）**：刀具是一个球头/胶囊笔刷，沿手势路径对坯体做减法，削出**弧形凹槽**（不是平面切口）。从任意表面下刀，不限制起始角度
    - 反复平行刮同一区域 → 凹槽连成凹槽带，**边缘被削成扇贝状波浪**（参考图的标志性视觉）
    - 两种基础手法：**宽扫**（刀头半径大、削得浅而宽，一次带走一整片，边缘快速扇贝化，容易撞到浅层侧腔）｜**深钻**（刀头半径小、窄而深，原地越挖越深，最快接近核心腔）；沿表面均匀推进的"环切"放到V1.1
    - 厚度可读：切面颜色随"距原表面的深度"变化（浅→深三层色带），且**切面比外表更哑光、略深、颗粒更细**——这是立体减材天然产生的层感，不需要额外画色带（做法与注意事项见 2.4）
    - 慢速滑动：削出连续卷片，卷片成条状飞出并保持形状
    - 快速滑动：碎粒飞溅、更容易崩边
    - 斜向滑动：凹槽走向随手势，凹槽截面形状由刀具决定
    - 锤子工具点击：直接砸碎坯体
4. 埋藏腔与揭示规则
    - 每坯埋藏腔数量 N=1~6：按**坯体体积**估算（约每 1200mm³ 一个腔），并受最小间距与夹角约束，下限1、上限6
    - 点位按"**距表面深度**"分四档：浅（0~8mm）｜中（8~16mm）｜深（16~26mm）｜核心（最深处，即最大内切球位置）
    - 核心腔是主藏品唯一可能出现的位置；其余为小物腔（只出小物或空腔）
    - 核心腔判定（**主藏品率随稀有度递增，越稀有越不容易空手**）：普通 空腔40%｜小物20%｜主藏品40%｜稀有 空腔35%｜小物20%｜主藏品45%｜史诗 空腔30%｜小物20%｜主藏品50%｜传说 空腔20%｜小物20%｜主藏品60%
    - 小物腔判定：空腔60%｜小物40%
    - 空腔也给 1 枚「空响币」：每个刮开的埋藏腔至少产出 1 币，整局不会出现 0 收益（这是"无0收益出口"的兜底，不可取消）
    - 主藏品＝该坯固定的隐藏摆件，首次刮出即录入图鉴；小物＝通用素材，折算星光币，不计入图鉴
    - 深度在开局冻结：腔位固定在体素空间内，刮削只改外形、不改腔位与档位；腔位不会被刮跑，核心腔揭晓前始终保留一层薄材料
    - 结构信号：距腔位3mm内，摩擦声变闷（低频+15%）、刀头阻力约+10%、切面粉屑轻微聚集；空腔与有物腔信号完全一致，只提示"这里有结构"，不提示内容
    - 碰到隐藏摆件时，摆件不会被切碎；锤子可以主动砸碎摆件
    - 传说坯触发专属慢镜头+全屏粒子特效（广告素材核心镜头）
5. 一局结束与结算
    - 一局＝一个坯，从坯体落到手里到核心腔揭晓完成，约30~70秒；N=1~2 的小坯单局约20秒
    - 结束路径共5条：自然揭晓｜手动收工｜砸碎坯体｜砸碎摆件｜挖穿兜底（判定表见 2.3）
    - 完整顺利开出：全额星光币；砸碎坯体、破坏隐藏物：30%保底星光币；无扣分、无失败判定
    - 揭晓仪式：0.4s停顿+0.8s慢镜（传说2s），可点击加速，随后弹出结算卡
    - 中途退出：坯体作为半成品存档可继续；未结算不产币

### 模式B：自由沙盒（**V1.1 上线，V1.0 完全不展示入口**）
> 本模式**不产出星光币、不计入图鉴**，纯粹解压
> V1.0 不建入口、不做宣传；V1.1 随新套装一起上线，作为第二个卖点
1. 玩家自由选择材质、配色分层、坯体形状、工具
2. 子模式（V1.1 一并提供）：
    - **有限层数模式**：坯有固定厚度，刮完自动重置
    - **无限漫游模式**：采用"大体积坯 + 自动补料"方案——坯体做到很大，刮到临界尺寸时**自动补一圈新材料**（在密度场上把被削掉的区域按材质回填），视觉上源源不断，实现"持续刮削"；不做"无厚度上限"这种与体素有限体积冲突的设定
3. 支持一键重置坯体、随时更换配色与材质，没有任何收集目标
4. 后期（V1.2+）开放自由塑形：精细雕刻（小刀头半径），玩家可从任意坯体刮出自己想要的形状；只减不加（如石雕），想刻细长形状需先选足够大的初始坯体
> **体素方案对沙盒是加分项**：自由塑形在 2D 遮罩模型下几乎做不了（只能轮廓收缩），在体素减材下是天然能力——这也是选 R2 的长线理由。

## 2.2 红线规则（严格遵守，防止解压变焦虑）
❌ 没有每日任务、打卡、排行榜、对战、体力值
❌ 没有星级评价、完美切割判定、扣分机制
❌ 没有强制分享、强制看广告
❌ 不锁池、不按顺序解锁池、不设"今日必做"
✅ 任何坯体，随时点击【重置坯体】复原
✅ 随时退出当前坯，返回大厅，进度不强制保留
✅ 限定池只显示"活动期间"，不显示精确倒计时

## 2.3 一局结束与结算判定表
| 结束路径 | 触发条件 | 结算 | 图鉴 |
| ---- | ---- | ---- | ---- |
| 自然揭晓 | 核心腔被挖开（无论空/小物/主藏品） | 已开出的全部收益 | 出主藏品则收录 |
| 手动收工 | 核心腔已挖开后点【收工】 | 已开出的全部收益 | 同上 |
| 砸碎坯体 | 锤子命中坯体核心 | 已开出的收益 + 该坯主藏品全额×30%保底 | 同上 |
| 砸碎摆件 | 锤子命中主藏品本体 | 已开出的收益 + 该坯主藏品全额×30%保底 | 收录（首次暴露即收录） |
| 挖穿兜底 | 坯体被削到最小残余体积仍未判定（异常） | 全额 | 收录 |

- 收工后未挖开的埋藏腔自动作废，不作惩罚（玩家本不知道其存在）
- 挖到小物腔不会中断本局；主藏品揭晓后仍可继续挖剩余腔
- 一局内主藏品最多产出一次；重复获得已收录款按全额折算星光币
- 结算保底：每个已挖开的埋藏腔（含空腔）至少结算 1 枚空响币，因此**任意一局的金币收益 ≥ 本局埋藏腔数**，不存在 0 收益局
- **挖穿兜底的触发条件**：残余体积 < 初始体积的 8%（正常玩法几乎不会触发，只用于兜住"玩家把坯刮成一张薄片"的极端情况）

## 2.4 信息与决策设计（可玩度支撑）
> 原则：信息只给"结构"，不给"答案"；决策只给"不同的收益形状"，不给"失败"。

### 2.4.1 信息层（三件）
1. **厚度可读**：切面颜色随"距原表面深度"变化——削掉一层露下一层，共三层色带（每层约 8mm）；同时**切面比外表更哑光、略深、颗粒更细**，给出"这一刀挖了多深"的直觉。立体坯的凹槽本身就有明暗（凹底背光更暗），是天然的厚度提示
2. **结构信号**：距埋藏腔 3mm 内，摩擦声低频+15%、刀头阻力约+10%、切面粉屑轻微聚集；空腔与有物腔信号完全一致
3. **中性进度环**：屏幕角落显示"已削体积/初始体积"的环形指示，不评分、不判定、不弹提示

### 2.4.2 决策层（三招）
1. **手法选择**：宽扫（刀头半径大，削得浅而宽，一次带走一整片，侧腔机会多）｜深钻（刀头半径小，最快接近核心腔，通道窄）；首版两档，环切V1.1
2. **下刀位置**：从最厚处下刀最快接近核心；从薄处下刀摊得广、离核心远——由厚度信息自然导出，不需要额外系统
3. **收工时机**：核心腔挖开后即可随时收工；收工后该坯未挖开的侧腔作废、本局结束，不惩罚，但"再扫两刀还是现在结算"从此有了分量
4. **转动角度**：转坯不是纯装饰——转过去能削到"刚才看不到的那一面"，薄处/厚处的分布随角度变化，玩家会主动转着找"这一面还有多少料"

### 2.4.3 注意事项（防止设计跑偏）
- 厚度提示**不能做成精确等高线**：太精确会变成攻略，探索感消失；色带与凹槽明暗要"可感知、不可测量"
- 结构信号**必须覆盖空腔**：只给有物腔信号等于剧透，"信号=有货"一旦成立，读坯就变成找答案
- 信号强度控制在"比察觉阈值高一点点"：太弱等于没有，太强等于透视
- 手法**首版只做两档**：三种以上会造成选择过载，且与"解压"定位冲突
- 收工作废**必须配文案**（"本局已收工，剩余点位不再保留"），否则玩家会以为没刮完是bug
- 进度环**只是仪表**：不显示分数、不做颜色警示，避免变成隐性评分
- **转动不能变成负担**：触控盘必须"**抬手即停、可一键回正**"，且**刮削时不需要持续转动**——转是"为了换面"，不是"为了操作"。**不要加惯性拖尾**：玩家要的是"转到哪个角度就停在哪个角度"，惯性会让每次定位都要多等半秒

### 2.4.4 验证方法（灰盒5人）
1. 关掉提示后，玩家能否说出"这块哪里最厚"——验证信息可读
2. 一局内玩家是否主动换刀——验证手法有价值
3. 核心腔揭晓后，玩家会立刻收工还是继续扫侧腔——验证收工时机是否成为决策
4. 一局内玩家**主动转动坯体的次数**是否 ≥3——验证立体旋转是否被真正用起来（若几乎不转，说明角度没有信息价值，应减少触控盘的视觉权重）

> 三条中两条不成立 → 回退到"只做信息层、不做手法"。

## 2.5 操作节奏与新手引导（**3D 方案必须做，不能省**）
> 立体减材 + 双触控盘是本作最大的卖点，也是**最不直观**的部分。2D 小游戏的"手指在图上划"是常识，3D 的"按住角上的盘转、再在坯上刮"不是。**没有引导，第一局会有一半人不知道能转**。

### 2.5.1 一局内的操作节奏
```text
看一眼（坯体缓慢自转展示，0.5 圈）→ 转（按住触控盘，把要削的面转到正面）
  → 刮（另一只拇指在坯上划，削出凹槽，卷片飞出）→ 看到厚度/结构信号
  → 再转（换面）→ 再刮 → …… → 挖到核心腔 → 收工
```
- **转与刮是两个动作，不是一个**：这是本作的操作特征，不要试图合并
- 熟练玩家可以**左手持续转、右手持续刮**，削出螺旋切面（参考图的真实动作）
- **一局内正常会转 3~8 次**；如果玩家整局不转，说明他没学会或者没必要转，两个都是问题

### 2.5.2 新手引导（只做一次，3 步，不打断）
| 步 | 时机 | 提示方式 | 内容 |
| ---- | ---- | ---- | ---- |
| 1 | 第一局开始，坯体出现后 | 左侧触控盘脉冲发光 + 一个手指拖动的动画示意（2 秒） | "按住这里，把坯体转过来" |
| 2 | 玩家转了 ≥30° 后 | 立即消失，改为坯体上出现一条虚线刮痕示意 | "在这上面划一刀" |
| 3 | 玩家刮出第一刀后 | 消失，不再提示 | — |

- **不弹窗、不遮屏、不写大段文字**：用"发光 + 动画示意"，符合零压力定位
- **引导可以被无视**：玩家直接刮也能玩，引导 8 秒后自动淡出
- **只在第一局出现一次**，之后永不再现（不做"再看一次"入口，避免误触）
- **触控盘常驻可见**：即使不引导，盘也要一直半透明可见（透明度 30%），这是"能转"的唯一长期提示

> 验证：找 5 个没玩过的人，**不做任何口头说明**，看他们第一局内是否自己发现了"能转"。发现率 <60% 就要加强引导（提高盘的不透明度、加长示意动画）。

> 要求：音频底噪低，音量柔和，不刺耳

## 5.2 震动规范
- 适配微信小游戏vibrate接口，区分震动类型
- 支持全局一键关闭震动
- 线性震动：环形修坯刀、蜡质顺滑刮削
- 短促间断震动：冷皂脆切
- 低频柔和震动：果冻刮削

## 5.3 粒子与卷片特效分级
- **卷片（3D 网格，不是粒子）**：每刀按材质生成 1~3 条卷片，成条飞出、落地堆叠、若干秒后淡出；卷片是对象池复用的预制弯曲带条 mesh（4~6 个变体），**不要用 2D 碎片贴图代替**
- 普通坯：少量材质碎粒 + 标准卷片
- 稀有坯：细闪粉末粒子 + 卷片边缘带细闪
- 史诗坯：彩色闪粉粒子 + 卷片更长
- 传说坯：全屏粒子+慢镜头0.8倍速，高光停留1.5s（买量核心镜头）
- **卷片总量上限**：同屏最多 24 条，超出复用最旧的（低配模式 8 条）

# 6. UI页面架构&交互流程
整体风格：马卡龙低饱和柔光极简风，半透明UI，不遮挡游戏画面
页面清单：
1. **大厅首页（启动页）**
    - 顶部：游戏logo+slogan
    - 中间**唯一主按钮：【惊喜工坊】**（V1.0 不出现【自由沙盒】入口，沙盒配置页与相关资源不上线）
    - 次级入口：图鉴收藏室｜工具台｜设置

2. **盲盒抽取页（惊喜工坊入口）**
    - 池列表：常驻甜品工坊 / 常驻深海秘境 / 季节限定池，显示每池收集进度（已收集/总数/**还差X款**）与"限定"角标
    - 不锁池，可随时切换；同时在线池最多4个
    - 选中池后展示池预览、概率说明、抽卡按钮；"还差X款"在水印式小字里提示，用来点亮收集冲动（不弹窗、不催促）
    - 显示星光币数量、今日免费抽取标记；抽取券通用
3. **坯体操作主页面（核心游戏页）**
    - 85%区域：立体坯全屏 3D 操作区（相机绕坯体 orbit）
    - **左右两个触控盘（功能完全相同，都是 2 轴自由转动）**：分别放在左下、右下，直径约 140px（热区外扩到 180px）、半透明、按住才显形。拖向哪个方向，坯体就往那个方向转；**抬手就停在当前角度**，没有惯性拖尾。两个盘只是位置不同，方便左手或右手单手操作，**全程不需要双指**
    - 底部可收起悬浮工具栏：切换刀具｜重置坯体｜一键回正
    - 左上角：中性进度环（已削体积/初始体积），无分数、无颜色警示
    - 核心腔挖开后出现【收工】按钮，其余时间不显示
    - 右上角：返回大厅按钮
    - **触控分区**：落在触控盘热区 = 转动坯体；落在坯体上 = 刮削；落在空白 = 无响应（不误刮）
    - **拖出圈外仍跟手**：手指从盘内拖到盘外，旋转继续生效，直到抬手为止（否则只能转半个圈）
    - 刀头落点偏移：手指会挡住落点，刀头显示在手指上方约 40px 处，保证看得见挖在哪
4. **图鉴收藏室页面**
    - 分册Tab：常驻册（甜品/深海）｜年度限定册，完成度分别计算
    - 套装分组Tab，陈列收集到的隐藏摆件
    - 点亮/灰色未解锁区分，点击藏品重新把玩坯体（重温不产出星光币）
    - 套装完成进度条
5. **自由沙盒配置页（V1.1 上线，V1.0 不做、不展示）**
    - 材质选择、配色选择、坯体形状、模式切换【有限层数 / 无限漫游】（V1.1 一并提供）

交互流程：
打开小游戏 → 进入大厅 → **V1.0 唯一路线：惊喜工坊**

# 7. 商业化方案（微信小游戏纯 IAA）
> 核心原则：**收入全部来自激励视频；广告只在玩家主动点击时播放，绝不打断刮削；无内购、无付费去广告**
> 本作是**纯 IAA 产品**：不设任何付费入口，也不存在"免广告包"这类商品

## 7.1 广告位设计（V1.0 只做激励视频，0 插屏）

### 7.1.1 三类广告的取舍
| 类型 | 大致 eCPM | 是否采用 | 原因 |
| ---- | ---- | ---- | ---- |
| 激励视频 | 最高（约40~80元） | ✅ 主力 | 收入最高、玩家主动、不打断操作 |
| 插屏 | 约15~25元 | ❌ V1.0 不做 | 自动弹出，与"零压力/想停就停"冲突 |
| Banner | 约1~5元 | ❌ 永不采用 | 遮挡ASMR画面，破坏调性 |
| 格子/原生模板 | 约5~15元 | ❌ 不采用 | 会把治愈风做成信息流 |

> 插屏的 eCPM 只有激励视频的 1/3，但伤留存是后者的数倍；IAA 收入 = ARPDAU × 留存天数，所以**V1.0 一个插屏都不放**。V1.1 若次留 ≥35%，再考虑"结算后、每3局最多1次、带明确关闭键"的弱插屏。

### 7.1.2 五个激励视频位
> **兑换率原则**：每次广告15秒，换来的价值对标"正常游玩每秒约0.32币"。A/B 约16倍、C 约3倍、D 约1.6倍——越划算的位完播率越高，所以核心收入靠 A/B，C/D 是顺手补位。

| 位 | 位置 | 给什么 | 动机 | 上限 |
| ---- | ---- | ---- | ---- | ---- |
| **A 加抽**（核心位） | 抽卡页，免费抽用完后出现 | 一次抽取，传说概率提升至8% | ★★★★★ | **每日5次** |
| **B 免费抽+1** | 大厅，每日首次进入出现一次 | 额外1次免费抽 | ★★★★★ | 每日1次 |
| **C 结算双倍** | 结算卡底部，次级按钮 | 本局星光币**×2**（约等于多玩1局） | ★★★★ | 每局1次、每日3次 |
| **D 砸碎补救** | 仅在砸碎结算（30%保底）时出现 | 本局补到**70%** | ★★★★ | **每3局最多1次**、每日2次 |
| **E 刀具特效** | 工具台·刀具详情内 | 拖尾星光/花瓣特效（仅外观） | ★★ | 每日1次 |

位 D 的三条约束（防止诱导砸碎，也防止广告压过玩法）：
- **每 3 局最多 1 次**、每日 2 次，补到 **70%**（不是全额），补完后**不追加任何额外奖励**
- 文案写"补领一份奖励"，不写成"弥补损失"
- 广告奖励不得超过玩法本身一次产出，避免玩家把注意力放在"要不要看视频"而不是"怎么刮"

位 E 的作用不只是收入：它把广告从"我要东西"扩展到"我想好看"，让广告看起来是可选的装饰而不是收费墙。

#### 玩家路径上的广告触点图
```text
启动 → 大厅
  ├─ [位B] 每日首次进入：看视频免费抽+1              （每日1次）
  ├─【惊喜工坊】→ 池列表 → 抽卡页
  │     ├─ 免费抽（每日1次，不出现广告）
  │     ├─ [位A] 看视频抽一次（传说8%）              （每日5次）
  │     └─ 星光币抽（80币，不出现广告）
  ├─【自由沙盒】→ 配置 → 刮削                       （全程无广告）
  └─ 工具台 → 刀具详情
        └─ [位E] 解锁刀具外观特效                    （每日1次）

抽到坯 → 刮削（无广告：转动/埋藏腔/揭晓）
  └─ 结算卡
        ├─ 正常揭晓或收工 → [位C] 本局奖励双倍         （每局1次/每日3次）
        ├─ 砸碎（30%保底）→ [位D] 补领到全额         （每局1次/每日2次）
        └─ 返回池列表

❌ 以下位置永远不出现广告入口：
   刮削页 · 传说慢镜头播放中 · 图鉴翻阅 · 启动开屏
```

### 7.1.3 频率闸门（四层叠加，不可放开）
| 闸门 | 规则 | 作用 |
| ---- | ---- | ---- |
| **新手闸门** | **前 3 个已完成的局不出现任何广告位**（含位B），跨天不清零 | 先让玩家玩爽，再谈广告；这是"心甘情愿"的前提 |
| 单局闸门 | 一局内最多1次激励视频 | 保证刮削过程完全干净 |
| 冷却闸门 | 任意两次广告间隔 ≥30秒 | 防误触与连点 |
| 每日闸门 | 激励视频总计 ≤12次（分位：A5+B1+C3+D2+E1） | 防"广告刷子"打乱节奏 |
| 软闸门 | 某位连续3次"点了没看完"，临时降频 | 自动缓解广告疲劳 |

> 广告只允许出现在**抽卡页、结算卡、工具台**三个界面。**刮削页、传说慢镜头、图鉴翻阅时，一帧都不许有。**

### 7.1.4 禁用清单
- ❌ 刮削主页面 / 传说慢镜头播放中 / 图鉴翻阅时
- ❌ 启动开屏广告、原生插屏自动弹出
- ❌ 任何"必须看广告才能继续"的路径（等于收费墙，违反零压力定位）
- ❌ 视频中途无法跳过；广告遮挡操作区域

### 7.1.5 无填充与异常处理
- 无广告填充时提示"暂无广告，稍后再试"，**不扣次数、不扣奖励、不让玩家白等**
- 加载前显示"约15秒"提示，避免玩家以为卡死
- 看完但回调失败时，本地兜底补发奖励，并记录异常埋点

### 7.1.6 埋点与优化指标

**事件表（程序直接按这个埋）**
| 事件名 | 触发时机 | 关键参数 | 用途 |
| ---- | ---- | ---- | ---- |
| `ad_slot_exposure` | 广告按钮渲染出来 | slot, screen, day_index, coin_before | 算曝光量与点击率分母 |
| `ad_click` | 玩家点击广告按钮 | slot, screen, coin_before | 算点击率 |
| `ad_load_fail` | 广告拉取失败/无填充 | slot, errCode | 监控填充率，判断是否要换位 |
| `ad_start` | 视频开始播放 | slot, ad_unit_id | 算进入率 |
| `ad_abort` | 中途关闭/播放失败 | slot, progress_sec | 判断视频长度是否合适 |
| `ad_complete` | 视频播放完成 | slot, duration_sec, ad_unit_id | 算完播率 |
| `ad_reward_grant` | 发放奖励成功 | slot, reward_type, reward_amount, coin_after | 算实际收入与发放正确性 |
| `ad_reward_fallback` | 回调失败但本地补发 | slot, reason | 监控 SDK 稳定性 |
| `ad_blocked` | 被闸门拦截 | slot, scope(daily/round/cooldown) | 验证闸门生效 |
| `ad_dup_callback` | 同一 ad_id 重复回调 | slot, ad_id | 防重复发奖（安全） |

**公共参数（每条事件都带）**：`session_id`、`round_id`、`pool_id`、`bake_id`、`rarity`、`platform`（iOS/Android）、`is_first_open`、`day_index`、`app_version`

**核心指标看板（只看这六个）**
1. **每位置曝光→点击率（CTR）**：低于 3% 的位，说明入口太深或动机不足
2. **完播率**：低于 70% 的位，奖励不足或视频太长
3. **人均日观看次数**：健康区间 4~7 次；超过 9 次要检查是否在诱导
4. **广告后次日留存（A/B）**：开广告组 vs 未开广告组，掉超过 5 个百分点就要减位
5. **ARPDAU**：目标 0.3 元以上
6. **人均局数 / 人均观看次数比（广告替代玩法监控）**：正常应 ≥ 4:1；若人均局数下降 **>10%**，说明广告正在替代玩法而非加速玩法——**此时优先降位C，不要降位A**（A 是玩家主动要的，C 是顺手位，可牺牲）

> 判断逻辑：A 的价值高、玩家主动点，属于"加速器"；C 是结算页顺手位，一旦它比"再玩一局"更划算，就会把玩家从玩法里拽走。

**安全规则**：`ad_id` 唯一性校验，同一次播放只允许发奖一次；奖励发放以服务端/本地存档双写为准，避免回调丢失或重复。

### 7.1.7 上线前置
- 微信小游戏流量主需**累计独立访客 ≥1000** 才能开通，前 1000 用户为 0 收入
- 这段窗口正好测"无广告手感"的留存基线，开广告后再做对比
- 抽卡概率公示面板必须常驻；**"首次视频抽保底稀有+" 属于概率变更，必须在公示面板里单独注明**（合规要求，不能只在代码里实现）
- 隐私协议需写明"本游戏含激励视频广告，由用户主动触发"

### 7.1.8 收入参考（行业区间，以广告后台实际为准）
> 激励视频 eCPM 约60元 → 单次约0.06元；人均日观约6次 → **ARPDAU 约0.36元**
| DAU | 日收入 | 月收入 |
| ---- | ---- | ---- |
| 500 | 约180元 | 约5,400元 |
| 2,000 | 约720元 | 约21,600元 |
| 10,000 | 约3,600元 | 约108,000元 |
> 生死线在 DAU 3000 以上：**广告设计的第一目标是别把留存搞坏**，塞更多位换来 ARPDAU 涨、留存掉，总收入反而下降。
> 注：本表按"人均日观 6 次"估算（实际分位上限为 12 次），**上线后必须按广告后台真实完播数据校准**，不要拿本表做财务承诺。

### 7.1.9 广告位 UI 与文案规范

**样式规范（防止做得像收费墙）**
| 项 | 规范 |
| ---- | ---- |
| 按钮层级 | **次级样式**：浅底/描边，视觉权重低于主按钮；禁用高饱和主色填充 |
| 图标 | 播放三角 + 文字，不用"AD/广告"大字；不用红色、感叹号、闪烁动效 |
| 位置 | 结算卡内位于主按钮**下方**，与主按钮间距 ≥24px；绝不遮挡操作区 |
| 时长提示 | 按钮上标"约15秒"，让玩家有预期 |
| 状态反馈 | 加载中→"加载中…"（按钮禁用）｜无填充→"暂无广告"（按钮禁用）｜已领取→"已领取"（按钮置灰） |
| 退出方式 | 按钮旁提供"跳过"文字入口，点了直接关闭、不领奖励、不扣次数 |

**文案模板（动词 + 收益 + 时长 + 换算，不写诱导词）**
| 位 | 主文案 | 副文案（**必须写出"省下多少"**） |
| ---- | ---- | ---- |
| A 加抽 | 看视频再抽一次 | 约15秒 · 省下约4分钟刮削 |
| B 免费抽+1 | 看视频多得 1 次免费抽 | 约15秒 · 每天1次 |
| C 结算双倍 | 本局奖励翻倍 | 约15秒 · 等于多玩1局 |
| D 砸碎补救 | 补领一份奖励 | 约15秒 · 补到七成 |
| E 刀具特效 | 解锁这个外观 | 约15秒 |

> 兑换率要**能被玩家一眼算清**：15秒换来的是"A 约3分钟刮削价值、C 约1局刮削价值"。写不出来就说明这个位的奖励不够，应该调奖励而不是加话术。

**禁用词**：限时、立即领取、必须、免费领、错过就没了（诱导或虚假承诺）
**D 位文案特别要求**：写"补领一份奖励"，**不能**写"弥补损失/挽回损失"（避免放大挫败感）

**"不像收费墙"自检四条**
1. 不看广告也能玩到全部内容（图鉴/池/沙盒都不锁）？
2. 广告按钮是次级样式、不是主按钮？
3. 没有任何倒计时或"再不看就没了"的压迫感？
4. 广告入口不遮挡刮削操作区？

### 7.1.10 上线前后的广告验证计划

> 核心原则：**一次只加一个广告位**，每次观察 3 天，任何一位导致留存下滑就回退。

| 阶段 | 动作 | 观察指标 | 判定 |
| ---- | ---- | ---- | ---- |
| 阶段 1（0~1000 UV） | **0 广告**，纯玩法 | 次日留存、人均局数、人均时长 | 建立基线；若基线就很差，先修玩法而不是加广告 |
| 阶段 2（开通流量主后） | 只开**位A**，50% 用户灰度 3 天 | 次留、人均局数、ARPDAU | 次留掉 >5 个百分点 → 回退 |
| 阶段 3 | 位A稳定后加**位C** | 同上 | 同上 |
| 阶段 4 | 加**位B** | 同上 | 同上；B 在大厅，注意首屏体验 |
| 阶段 5 | 最后加**位D、位E**（D 风险最高，单独 A/B） | 同上 + 砸碎率变化 | 若砸碎率异常上升，说明在诱导，立即下线 D |

**没有流量主时怎么测**：用**本地 mock 广告**（假视频 15 秒倒计时）验证 UI、闸门、埋点、发奖逻辑，不依赖真实 SDK；等开通后再接真广告。
**发布前**用微信开发者工具的广告调试模式跑一遍五个位。

**灰度靠配置切换，不改代码**（字段见附录3 `ads`）：
- `slotsEnabled` 逐个开关五个位 → 对应阶段 2~5 的"一次只加一个"
- `grayPercent` 按用户稳定分桶放量（0 / 50 / 100）→ 阶段 2 的 50% 灰度

# 【方案B】Cocos Creator 立体减材实现思路 + 性能避坑清单
## 核心实现思路（体素 SDF 减材，微信小游戏可行）
> 推荐采用「**体素 SDF 减材 + 局部 Marching Cubes 重建**」方案。不做多边形布尔，不做物理碎片模拟，不做 GPU raymarching。
> 一句话：坯体是"一坨密度场"，刀是一个球头，削 = 在密度场上做减法，削完把脏掉的那一块重新生成三角面。

### B.1 为什么不用 2D 遮罩，也不做 raymarching
| 方案 | 为什么否决 |
| ---- | ---- |
| 2D 遮罩侵蚀（原方案） | 没有厚度、没有凹槽、削不出卷片，参考图的三样核心一个都做不了 |
| GPU raymarching（SDF 直接画） | 填充率在微信低端机上不可控；全屏步进 40~64 步 × 540×960 是自杀 |
| 多边形布尔 / 物理碎片 | CPU 必炸，低端机 100% 卡死 |
| **体素 + MC 局部重建（选它）** | 三角面数量由**表面积**决定（约 8k~20k），不由体积决定；渲染是普通网格，光照/阴影/材质全部白送；拾取用 CPU 光线步进，不需要物理引擎 |

### B.2 数据层（三层，全部是普通数组，没有引擎黑魔法）
1. **密度场 `density`**：`Uint8Array(48*48*48)`，0=空，255=满。48³ = 110,592 字节 ≈ **108KB**，随便存
   - 低配模式降到 `32³`（32,768 字节）
   - 传说款/异形款可提到 `56³`（175,616 字节），按坯配置分辨率
2. **原始距离场 `originDist`**：同一尺寸的 `Uint8Array`，记录"每个体素到**初始表面**的距离（归一化 0~255）"。**这个数组在刮削中永不修改**——它是"挖了多深"的唯一依据
3. **埋藏腔表**：`[{x,y,z,radiusMm,tier}]`，开局生成后冻结，与密度场完全解耦（腔位不会被刮跑）

> **关键**：`originDist` 让"三层色带""深度分档""进度环"全部变成一次数组查询，**零额外计算**。这是 2D 距离场思路在 3D 里的正确迁移。

### B.3 几何生成（坯体零模型资产）
1. **造型配方**：每款坯 = 一组 SDF 基础体 + 布尔/平滑并集 + 变形算子 + 噪声种子（详见附录1 二）
2. 离线/开局时把 SDF 采样进 `density`（一次，约 10~30ms，放在加载动画里）
3. 同时算一次 `originDist`（对 `density` 做一次三维距离变换，约 20~40ms）
4. 两件事都只在开局做一次，**运行时不再全量重算**

### B.4 减材（笔刷）
```
每帧拿到手指位移 → 投影成一条从相机出发的射线
射线在 density 上做 DDA 步进，找到第一个"实体表面"命中点 P（最多 ~120 步，纯整数运算）
以 P 为中心、刀头半径 R 为半径，把球内体素密度按材质参数削减（不是直接置 0，按"削深"衰减）
把受影响区域的 chunk 标记为 dirty
```
- **刀头形状**：环形修坯刀 = 球头（挖出弧面凹槽）；细线切割器 = 胶囊/细圆柱（窄而深）；齿纹刀 = 球头 + 表面正弦扰动（凹槽带齿纹）
- **宽扫 vs 深钻**：只是 `R` 和"单帧削减量"两组参数，不是两套逻辑
- **薄处削深调制（必须做）**：`实际削深 = min(刀头削深, 局部厚度 × 0.6)`。局部厚度直接读 `originDist`（2×距离值）即可，零额外开销
  - 不做这条的后果：薄处一刀穿透（因为刀头削掉的是固定半径的球），玩家会感觉"莫名挖穿"，破坏"可控"的解压感
  - 做了这条的后果：薄处自然变"刮得浅、刮得慢"，厚处正常 —— 这反而是好的手感层次
- **材质差异**：动力沙削得慢但连续｜冷皂削得快但边缘按概率崩缺｜果冻削后缓慢回弹（把削掉的密度**部分还原**）｜奶油蜡最顺滑、内壁最光滑

### B.5 渲染（局部重建，这是性能关键）
1. 把 48³ 切成 **6 个 24³ 的"大块"**（每块一个 `MeshRenderer`），或 8 个 16³~24³ 的块
2. 只有被笔刷碰到的块才重算 Marching Cubes，并**只重传这一块的 vertex/index buffer**
3. 单块重建目标 **< 3ms**；一帧最多重建 2 块，其余排队到下一帧（削的时候人眼看不出 1~2 帧延迟）
4. 顶点属性只保留 `position + normal + 一个"深度"标量`；**不做 UV**，材质走**三平面投影（triplanar）**
   - 三平面：按法线主轴混合 3 次采样，任意造型都不需要 UV 展开，正好配合"形状任意"
5. 切面着色：`color = f(originDist)` → 三层色带 + 凹槽底部压暗；再叠一层"切面比外表更哑光"的 roughness 差异

### B.6 拾取与旋转
1. **拾取不用物理引擎**：CPU 对 `density` 做 DDA 光线步进，比三角面 raycast 更便宜也更准（还能顺便判断"这一刀挖到多深"）
2. **旋转 = 相机 orbit**（不是转物体）。原因：笔刷永远在世界空间，**转走再转回痕迹天然保留**，不需要任何坐标系转换
3. **双触控盘**：**两个盘功能完全相同**，每个都是 2 轴自由转动（水平拖动→方位角，垂直拖动→仰角），放两个只为左右手都能单手用，**不需要双指**
   - **关键实现约束**：必须做成"**分轴映射**"（水平拖只改方位角、垂直拖只改仰角），**不要做成 arcball/trackball**（拖拽方向决定旋转轴）——arcball 会引入 roll，物体就会"歪着转"，玩家会晕
   - 方位角不限（360°），仰角限制在 ±85°（能看遍所有侧面，但不会转到底朝天迷失上下）
   - **抬手即停，无惯性拖尾**；`roll` 锁死
   - 灵敏度约 0.55°/px，且**拖出盘外仍继续跟手**（否则最多只能转 77°，够不到一圈）
4. **不做双指操作**（V1.0 明确不做，避免与刮削抢触摸，也避免玩家误以为要两指才能转）；"一键回正" = 相机插值回初始角度

### B.7 卷片（ASMR 主音画）
- 预制 4~6 个"弯曲带条" mesh（宽 8~20mm、厚 2~4mm、长 40~120mm，带一点弯曲）
- 每刀按刀速生成 1~3 条：从命中点沿刀路方向飞出，带自旋 + 抛物线 + 落地堆叠
- **对象池复用，同屏上限 24 条**（低配 8 条），超上限回收最旧的
- 材质参数决定卷片形态：动力沙宽厚带沙粒｜冷皂短且易断｜果冻薄且会塌｜奶油蜡超长连续

## 性能避坑清单（微信小游戏重点，防止闪退、掉帧）
✅ 密度场用 `Uint8Array` 而不是 `Float32Array`：体积只有 1/4，且 DDA 步进全是整数比较
✅ **只重建脏块**，绝不整场重建；一帧最多 2 块，其余排队
✅ 顶点属性砍到最小（position + normal + 1 个标量），不传 UV、不传切线
✅ 卷片、碎粒、闪粉、金币粒子全部对象池复用，不要每次 new/destroy
✅ 三平面采样用 `texture2D` 3 次 + 一次法线权重，不要写循环
✅ 关闭不必要的后处理：只保留简单柔光，不开 bloom 高配；做高低配画质开关
✅ 贴图压缩 ETC2，单张不超过 1024×1024
✅ 震动控制：短震动，不要持续高频震动，iOS 有调用频次限制
✅ 资源懒加载：图鉴、套装资源分包加载，启动只加载首页 + 当前套装
✅ **重建期间不 GC**：预分配所有 buffer，重建只写不建
❌ 不要用 Box2D/物理引擎做碎片模拟，微信低端机必卡
❌ **不要用 GPU raymarching 画坯体**：填充率不可控，低端机直接掉到个位数帧
❌ 不要做多边形布尔（Clipper/CSG）逐笔求交
❌ 不要每帧重建整块 mesh：20k 顶点全量上传 = 每秒几十 MB，必掉帧
❌ 不要在触摸回调里做重建：重建统一在 `lateUpdate` 里按 dirty 队列处理，避免一帧重建多次

## 兼容注意
- 微信小游戏不同机型性能差距极大，增加【低配模式】开关：密度场降 32³、卷片降到 8 条、关闭粒子与慢镜头
- **分辨率按坯分档**：普通/稀有 40³，史诗 48³，传说 56³——把算力花在买量镜头上
- 测试重点：安卓低端机（骁龙 6xx 及以下）、微信 iOS 端
- **判定为什么不回读像素**：微信小游戏从 RenderTexture 读像素不可靠且极慢，判定一律走 CPU 密度场

## 〇、包体预算表（体素方案）

### 2.1 造型硬约束（**自动体检，不过不许进包**）
> 这四条不是美术偏好，是体素分辨率 + 刮削机制硬性决定的。**它们限制的是"厚度"，不是"形状"**——歪、缺角、扇贝边、表面凹凸全都可以。

| 约束 | 阈值 | 为什么 |
| ---- | ---- | ---- |
| 最小局部厚度 | **≥10mm**（≈6 体素） | 更薄的部位在 48³ 下只剩 2~3 体素，网格化后会锯齿/断裂 |
| 连接处（颈/腰） | **≥10mm** | 细颈会被一刀削断，变成悬浮孤岛 |
| 最大内切球半径 | **≥12mm** | 没有够厚的"肚子"，核心腔无处安放，整局没有主藏品 |
| 单连通 | 必须 | 镂空环、悬空把手会先断成两块 |
| 尖端圆化 | 半径 ≥3 体素 | 尖刺的体素不足以支撑网格，会破面 |

**允许的"不规整"**：歪斜、缺角、扁/鼓、表面凹凸、噪声起伏、多体融合的葫芦形、半球伞盖、碗、螺旋。
**禁止的"不规整"**：细长触角/鹿角、薄片/翼/鳍、细颈、镂空环、尖刺、多分支。
> **参考图正好是"允许"的典型**：那块绿坯歪、缺角、边缘扇贝状，但整体很"肉"，没有一根细杆——所以它成立。
> 若某款确实需要"尖"的造型（如甜筒底），做法是**圆化收口**：锥体收到 10mm 圆头，而不是收到尖点，观感仍然是"锥"。

> **配色交付要求（必读）**：每款坯只交 **1 张中性色底图**（明度居中、饱和度低），**不要交 3 张配色版**。3 色变体由程序用 shader 色相/明度参数生成；验收时若发现"每色一张贴图"，一律退回。
> **切面质感要求**：贴图必须同时能表达"外表"和"切面"两种质感——外表更光滑、切面更哑光、颗粒更细、略深。用 1 张图的 roughness/法线差异实现，**不要交两套贴图**。

## 单人开发风险点 & 缓冲预留
1. 微信广告SDK审核经常驳回，预留1~2天修改缓冲；**纯 IAA 无内购**，不涉及支付与版号
2. **最大风险是动态网格重建的 GC 抖动**：低端机上表现为"刮两下卡一下"，优先用预分配 buffer + 脏块限流解决；解不掉就走阶段0 的降级方案
3. 低端安卓性能不足时，优先**降密度场分辨率（48³→32³）**、降卷片数量，不要降触控采样率（那会毁手感）
4. 美术会占用大量时间，**先做核心坯的造型配方 + 4 个传说隐藏物**，次要UI、普通粒子可以后补，先跑通核心玩法
5. **手感调优（阶段5）不可压缩**：压缩它等于压缩这个品类的唯一护城河
6. **3D 美术产能是新的风险点**：16 个隐藏物从 2D 贴图变成 3D 低模，如果自建模型卡住，先用"基础几何拼装 + 材质"顶上，不要为单个隐藏物卡 3 天

> **体素字段说明**：`voxel.gridNormal/Epic/Legend` 是按稀有度分配的分辨率（把算力花在买量镜头上）；`gridLowSpec` 是低配模式降级值；`chunkDivisions`=6 表示把 48³ 切成 6 个块，只有脏块才重算网格；`maxRebuildPerFrame` 限制每帧最多重建几块，防止卡顿；`voxelSizeMm` 是体素边长（1.6mm 下 48³ ≈ 77mm 见方）。
> **造型配方说明**：`primitives` 是 SDF 基础体（**可以多个**，靠 `smin` 融合成一个体），`ops` 是算子——`smin`（平滑并集，k 越小越"两半"、越大越"一坨"）、`subtract`（减去，做缺角/凹坑/碗）、`shear`/`bend`/`twist`/`scale`（变形，做歪/弯/旋/扁），`noise` 是表面噪声扰动。**这四类组合即可得到任意"粗壮的不规整"造型，不需要建模。**
> `check` 是自动体检阈值：`minLocalThicknessMm`（最小局部厚度，防止细部被刮断）、`minNeckMm`（连接处最小宽度，防止细颈断成两块）、`tipRadiusMm`（尖端圆化半径，防止尖刺破面）、`occupancy`（体素占用率区间）、`maxInscribedRadiusMm`（保证有地方放核心腔）、`singleConnected`（不允许碎成多块）。**体检不过的配方不许进包。**
> **造型自由度边界**：允许"歪/缺角/扁鼓/凹凸/葫芦/伞盖/碗/螺旋"，禁止"细长触角/薄片/细颈/镂空环/尖刺/多分支"。这不是创意限制，是"体素分辨率 + 刀头半径"的物理限制，详见附录1 第 2.1 节。
> **相机字段说明**：`dialCount: 2` + `dialFunction: "identical"` 表示左右两个触控盘**功能完全相同**（都是 `twoAxisFree` 2 轴自由转动），只是位置不同方便左右手；`handedness` 是利手设置（`both` 默认双盘 / `left` 仅左 / `right` 仅右）；`twoFingerOrbit: false` 表示**双指操作一律不响应**；`sensitivityDegPerPx` 是拖动灵敏度（0.55°/px）；`trackOutsideCircle: true` 允许拖出盘外继续转（**必须为 true，否则转不满 360°**）；`inertiaDamping: 1.0` 表示**抬手即停、无惯性**；`azimuthRangeDeg` 水平方向不设限（360°）；`elevationClampDeg` 仰角限制在 ±85°（能看遍所有侧面，但不会转到"底朝天"让人迷失）；`rollLocked: true` 锁死翻滚——**2 轴输入本身就产生不了翻滚，这条是给实现方的约束，不要额外加 roll**。
> 广告灰度字段说明：`slotsEnabled` 控制五个位逐个上线（灰度期只开 A/C）；`grayPercent` 是按用户稳定分桶（哈希 openid）决定看到广告的用户比例，0=全量关闭、50=半量灰度、100=全量；`mock.enabled` 打开后用本地假视频（`durationSec` 秒倒计时）走通 UI/闸门/埋点/发奖，不依赖流量主；`rollbackThreshold` 是**写死的回退线**（次留掉超过 5 个百分点或人均局数掉超过 10%，对应位下线），不是建议值。

## 四、坯体怎么做（**造型配方 + 材质贴图，不建模、不画轮廓**）
> ⚠ **这一节已经完全改掉**：坯体是**立体**的，由程序按"造型配方"在运行时生成几何。你不画轮廓、不做模型，只做两件事：**调造型参数** + **画一张材质贴图**。
> 旧写法"坯体是一张平面贴图，贴在 Mesh 上，不是 3D 模型"**作废**。

### 4.1 造型配方怎么调（这是新的"美术活"）
1. 每个坯 = `primitives`（基础体：roundBox / sphere / cylinder / cone，**可以多个**）+ `ops`（平滑并集 smin / 减去 subtract / 变形 shear·bend·twist·scale）+ `noise`（噪声种子与幅度）
2. 调参口诀：**先定体块关系（几块怎么拼）→ 再定胖瘦（size）→ 再定圆角（radius）→ 再加减法做缺角/凹陷 → 最后加噪声（0.5~1.5mm）**
3. **四个维度做差异**（都在"粗壮"范围内，够出 16 款完全不同的坯）：
   - **体块关系**：单体 / 双体融合 / 球+锥 / 球减球（碗）/ 半球
   - **变形**：剪切（歪）、弯曲（弯）、压扁（扁）、扭转（旋）
   - **表面**：噪声起伏、小球凸起、凹坑
   - **比例**：扁 vs 高 vs 矮胖
4. **必须过的体检（脚本自动跑，不过就改参数）**：
   - **最小局部厚度 ≥10mm**（低于这个，刮两下就断成孤岛）
   - **连接处（颈/腰）≥10mm**
   - 体素占用率 35%~70%（太满像盒子，太空像骨架）
   - 最大内切球半径 ≥12mm（保证放得下核心腔）
   - 单连通（不允许碎成两块）
   - 尖端圆化半径 ≥3 体素
5. **"粗壮的不规整可以，纤细的不规整不行"**：
   - ✅ 可以：歪、缺角、扁/鼓、表面凹凸、噪声起伏、葫芦形、半球伞盖、碗、螺旋
   - ❌ 不行：细长触角/鹿角、薄片/翼/鳍、细颈、镂空环、尖刺、多分支
   - 想要"尖"（如甜筒底）→ **圆化收口**：锥收到 10mm 圆头，观感仍然是"锥"
6. 每款坯的造型差异要**一眼可辨**：盲盒的第一层惊喜是"这个坯长得不一样"，16 款长得像 16 个圆角盒，盲盒的期待感就废了一半

### 4.2 材质贴图怎么画（512×512；传说款 1024×1024）
1. 思路：**先AI生成参考图，再修图、统一色调、做成可平铺的无缝贴图**
2. 风格：哑光、柔和、干净，不要强烈光影（光影由引擎打，贴图里带光影会脏）
3. 材质差异：
   - 动力沙：柔和杂点颗粒纹理
   - 冷制皂：细腻均匀，轻微磨砂
   - 果冻：半透明通透渐变（配 alpha 与高透）
   - 奶油蜡：丝滑渐变，几乎没有噪点
4. **一张贴图要同时表达"外表"和"切面"两种质感**（必做）：
   - 外表：更光滑、亮一点、颗粒细
   - 切面：更哑光、略深、颗粒更粗、有细密拉丝痕
   - 做法：一张 baseColor + 一张法线/粗糙度图，程序按 `originDist`（挖深）在两者之间插值。**不要交两套贴图**
5. **配色只交 1 张中性色底图**：明度居中、饱和度低。3 色变体由 shader 色相/明度参数生成

> 避坑：贴图不要有硬黑描边；不要放复杂构图，坯是被反复切削的，细节太碎切完就糊；**不要画"轮廓/描边/阴影"**，那些在立体坯上全是错的。

## 五、隐藏物 3D 低模（**从贴图改为模型**）
- 隐藏物是**实心 3D 物体**，玩家挖到就停，不会被刮碎
- 规格：普通/稀有 ≤1500 面，史诗 ≤2500 面，传说 ≤4000 面；导出 GLB（可 Draco 压缩）
- 传说款额外多一张 **发光遮罩贴图**（256 单通道）：白色渐变，用来做自发光
- 尺寸要求：**直径不小于坯体最短边的 25%**，太小挖出来没存在感
- 例子：宝箱、水母、甜筒、珍珠
- 单人省事做法（按优先级）：
  1. 用**基础几何拼装**（球/柱/环/锥组合）再倒角，够用且零成本
  2. 用 AI 图生 3D（Meshy 之类的图生模型），出来再减面
  3. 最后才考虑手搓 Blender
> ⚠ 不要为单个隐藏物卡超过半天。它是"揭晓奖励"，不是主角——主角是坯体和刮削手感。

## 六、刀具图标、粒子贴图
- 刀具：256×256，透明底，简约扁平
- 粒子：
  - 沙粒：小圆点，浅棕
  - 果冻水珠：淡蓝渐变圆
  - 星光：四角星/十字柔光光斑
  - 金币粒子：小圆渐变黄色
> 粒子尽量简单！粒子太多、贴图复杂，微信低端机直接卡。

## 七、音效制作&版权（单人最容易踩坑）
✅ 优先 CC0 免费无版权素材（Freesound），商用没问题
❌ 不要直接拿抖音、B站的ASMR音频，有版权风险
操作：
1. 下载原始音频
2. Audacity降噪、剪掉爆音，统一音量
3. 导出 mp3：44.1kHz、**单声道 64kbps**（控制包体）
4. 分类命名：audio_material_sand_slow.mp3 这种，方便程序读取

## 八、单人开发美术的偷懒策略（非常重要，防止你被美术拖垮）
1. **同材质复用纹理**：8个动力沙坯，可以共用同一张沙子噪点材质贴图，只是颜色调色，不用每一张都重新画
2. **造型靠参数复用**：同系列坯用同一个基础体，只改 size / radius / noise seed，10 分钟出一款
3. 夹层纹理全局复用：糖粒、闪粉只做一张，多个坯共用
4. 隐藏物优先少而精：重点打磨4个传说隐藏物（买量镜头），普通隐藏物用基础几何拼装
5. 粒子贴图全部复用，只改颜色，不新增贴图
6. 卷片 mesh 只做 4~6 个变体，靠缩放/弯曲/颜色复用
7. 前期版本可以**不带复杂光效**，V1.0先保证玩法跑通，光效、装饰后面迭代加

## 九、Cocos导入贴图设置（必做，否则包体大、糊）
导入贴图的时候，在Cocos属性面板：
- 压缩格式：ETC2
- **材质贴图开启 mipmap**（3D 物体远近都需要，关了会闪烁）
- 过滤模式：Bilinear
- 图集打包：UI 打 SpriteAtlas；**材质贴图不进 UI 图集**
- 隐藏物 GLB：导入后**减面 + 开启 Draco**，检查面数是否符合规格
- **三平面材质**：材质贴图要设置为 Repeat（可平铺），因为三平面投影会重复采样

## 十、画风自检清单（画完一张对照）
- [ ] 整体低饱和柔和，没有刺眼大红大绿
- [ ] 没有厚重黑色描边（立体坯上描边是错的）
- [ ] 贴图可无缝平铺，接缝看不出来
- [ ] **同一张图能表达"外表光滑"和"切面哑光"两种质感**
- [ ] 尺寸符合规范，不超上限
- [ ] 文件名按命名规范，方便管理

## 6.12 组件8：双触控盘（**本次新增，核心交互组件**）
> **两个盘功能完全相同**，不是"左管水平、右管俯仰"。每个盘都是**2 轴自由转动**：拖向任意方向，坯体就往那个方向转。放两个只是为了让左手或右手都能单手操作，**不需要双指**。
尺寸：视觉直径 140px，热区直径 180px（热区比视觉大，好按）
图层结构（从上到下）
1. 底盘：圆形，填充 rgba(255,255,255,0.28)，1px 描边 rgba(68,68,68,0.15)
2. 方向指示环：一圈细环，拖动时环上出现一个**偏移的小光点**，指示当前拖动方向与幅度（回中即复位）
3. 中心握把：小圆点，primary_pink
4. 状态变体：
   - Idle：整体透明度 30%（几乎不挡画面，但仍可被发现）
   - Active（手指按住）：透明度 100%，底盘轻微放大 1.05
   - Limit（转到仰角极限）：描边变浅灰 + 一次轻微回弹（告诉玩家"到头了"）
> **摆放要求**：盘心距屏幕左右边缘各 90px、距底边 120px；**中间 400px 宽是净区**，坯体只占这块
> **触摸规则（三条，必须实现）**：
> 1. 热区优先于刮削判定：手指落在 180px 热区内，一律当"转动"，不触发刮削
> 2. **拖出圈外仍跟手**：手指从盘内拖到盘外，旋转继续生效直到抬手（否则最多只能转半圈，够不到 360°）
> 3. **抬手即停**：不做惯性拖尾。玩家要的是"转到哪个角度就停在哪个角度"
> **灵敏度**：`0.55°/px`（拖 650px ≈ 转一整圈）。因为可以拖出圈外继续拖，屏幕大小不构成旋转上限
> **两个盘互斥**：同一时刻只有一个盘生效（后按下的接管），先按的自动失效，避免双手同时拖导致角度打架
> **利手设置（可选，5 分钟工作量）**：设置里提供"双盘 / 仅左 / 仅右"三档，默认**双盘**。
> - 默认双盘 = 发现性最好，玩家自然用自己惯用的那只手
> - 左利手可选"仅左"，右利手可选"仅右"，减少一个盘的视觉干扰
> - **不要默认只显示一个**：新玩家看不到另一个盘，会以为只能单手、或者不知道还能换手
> **双指操作一律不响应**（V1.0 明确不做）：两指同时按下时，既不旋转也不刮削，避免"误以为要两指"和"与刮削抢触摸"
